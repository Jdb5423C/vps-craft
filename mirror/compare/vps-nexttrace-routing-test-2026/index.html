一、先泼盆冷水：商家说优化线路你别全信

很多新手买 VPS 最吃亏的地方，就是被商家宣传页上的 CN2 GIA 三网优化、9929 精品回程、CMIN2 移动专线这几个词忽悠，付款之前连路由都没看过一眼。等机器到手，晚上打开网站卡成幻灯片，SSH 敲命令要等好几秒才回显，才想起去查线路，这时候退款早就过了窗口期。这篇文章要教你的，不是怎么挑最贵的机器，而是怎么用 NextTrace 这个免费开源工具，三分钟看清你这台 VPS 到底走了什么线路，是电信 CN2 GIA、联通 9929、移动 CMIN2，还是最普通的 163 国际线路。看懂路由，你才不会被话术牵着鼻子走。

这里先说一个核心认知：线路好不好，决定权不在商家嘴上，而在回程路由里的 ASN 和网段。ASN 是自治系统号，相当于每个运营商在国际互联网上的身份证；网段是 IP 的归属规律。只要你会看这两样东西，任何商家都骗不了你。下面所有操作都不需要你有网络工程背景，照着命令复制粘贴就行。

二、NextTrace 到底是什么，凭什么比 ping 强

NextTrace 是一款用 Go 语言写的开源可视化路由追踪工具，最初由国内开发者 sjlleo 维护。它本质上是 traceroute 的升级版：传统 traceroute 只给你一串冷冰冰的 IP 地址，而 NextTrace 会在每一跳旁边自动标注 ASN、运营商名称和地理位置。换句话说，别人只能看到 59.43.246.17 这种数字，你一眼就能认出哦，这是电信 CN2 节点。对国内用户最友好的地方是，它内置了针对电信、联通、移动三网的快速测试模式，一条命令就能把三网回程一起跑出来，不用你自己去翻测试 IP 列表。

它相比系统自带的 traceroute 还有几个实用增强：支持 ICMP、TCP、UDP 三种探测协议；支持表格化输出、JSON 输出；支持生成可视化路由地图并分享链接；内置多种 IP 地理数据库，对国内网络环境做了专门优化。排查线路质量、验证商家宣传、分析跨境路由走向，它都是首选。最重要的是，它轻量、免费、安装只需要一行命令。

三、三分钟装好：Linux 和 macOS 各一行命令

安装非常简单，基本不需要编译环境。在 Linux 上，官方一键脚本是：

curl -sL nxtrace.org/nt | bash

如果你的网络访问 GitHub 较慢，可以用国内镜像加速：

bash -c "$(curl -Ls https://ghproxy.com/https://raw.githubusercontent.com/sjlleo/nexttrace/main/nt_install.sh)"

macOS 用户用 Homebrew 更省事：

brew tap xgadget-lab/nexttrace && brew install nexttrace

装完之后输入 nexttrace --version 能看到版本号就说明成功了。需要提醒的是，Windows 平台对它目前只是实验性支持，建议在你的 VPS（通常是 Linux）上跑，或者在本机用 WSL、macOS 终端来跑。测回程必须在 VPS 上执行，因为你测的是从 VPS 回到家里的路径。

四、核心玩法：怎么追踪三网回程

路由追踪要分清去程和回程。去程是从你家宽带到 VPS 的方向，回程是 VPS 把数据传回你家的方向。绝大多数人看视频、刷网页、下载文件，下载流量占九成以上，所以回程线路才是决定你体感的关键，这也是奸商最容易动手脚的地方。NextTrace 必须装在 VPS 上，才能测出真正的回程。几条最常用命令记下来：

  • nexttrace 你的家庭公网IP：追踪回程到你家宽带，默认 ICMP 协议，最常用。
  • nexttrace --tcp --port 443 你的家庭IP：用 TCP 443 端口测，更贴近真实 HTTPS 访问，适合目标禁 ping 的环境。
  • nexttrace --fast-trace：一键测北京、上海、广州、杭州的电信、联通、移动、教育网节点，最适合不想查 IP 的懒人。
  • nexttrace --table 1.0.0.1：表格化输出，方便截图保存和横向对比。
  • nexttrace --rdns 目标IP：打开反向 DNS 解析，能看到节点域名，比如 iij.ad.jp、ntt.net，帮助你判断线路归属。

顺便说一句，怎么拿到你的家庭公网 IP？直接百度搜 IP 两个字就能看到，或者在路由器的 WAN 口状态里查。把这个地址填进上面的命令即可。如果你用的是大内网 CGNAT，没有公网 IP，那也可以用 nexttrace --fast-trace 让脚本自动选各运营商的探测点，照样能判断回程质量。

五、怎么读结果：认准这几段 ASN 和 IP

跑完之后，重点看每一跳括号里的 ASN 和网段。判断线路质量，记住一条铁律：看核心段，也就是大概第 5 跳到第 12 跳，而不是前几跳。前几跳是你家本地接入网和省内汇聚节点，无论你买多贵的机器，数据包都得先走这一段所谓的最后一公里，全是普通 IP 非常正常，别被吓到。真正的分水岭在中途——如果中途出现 59.43、218.105、223.118 这类精品网段，说明走了高端线路；如果一路都是 202.97、219.158、223.120 然后直接出国，基本就是普通国际线路。

另外要关注丢包和延迟稳定性，而不是只看有没有绕路。一个技巧是用 MTR 做交叉验证：在 VPS 上装 mtr，执行 mtr -rw -c 100 你的家庭IP，看每一跳的 Loss 列。优秀线路的全程丢包应低于 0.5%，延迟波动小于 50 毫秒。建议晚上 9 点再跑一次，那才是真实的晚高峰数据。NextTrace 看 ASN，MTR 看丢包，两者配合基本能定性一条线路。

七、实战一：一眼分辨 CN2 GIA、CN2 GT 和 163

电信用户最常踩的坑，是把 CN2 和 CN2 GIA 混为一谈。真正的 CN2 GIA 全程走 AS4809，路由里几乎全是 59.43 开头的节点，去程和回程都优质，晚高峰延迟和丢包都极低，是建站、电商后台、金融接口的黄金标准。CN2 GT 是降级版：国际段走 CN2，但国内段会混回 163 骨干，路由里 59.43 和 202.97 交替出现，价格便宜一些，晚高峰仍可能波动。最普通的 163 线路全程都是 202.97，晚高峰一堵，延迟飙升、丢包频发。

记忆口诀：节点全 59.43 是 GIA，混着 202.97 是 GT，全是 202.97 是 163。还要补充一点，CN2 GIA 的价格往往是普通线路的 3 倍以上，所以如果你看到商家卖得比普通线路贵不了多少却号称 GIA，就要警惕了——很可能只是 GT 或者混合线路。用 nexttrace 看 ASN 是唯一的照妖镜。

八、实战二：联通 9929 和普通 4837 怎么看

联通的精品网是 AS9929，也叫 CUII 或者 A 网，关键网段 218.105.x.x；普通网是 AS4837，也就是 169 网，网段 219.158.x.x。很多高性价比套餐玩非对称路由：去程走便宜的 4837，因为你发请求数据量小，省成本；回程走 9929，因为服务器传视频数据量大，要保证体验。所以你用 traceroute 看去程看到 219.158 别急着喊坑——登到 VPS 上跑 nexttrace 看回程，只要回程出现 218.105 和 AS9929，这条线路就是真 9929 回程，晚高峰照样稳。

反过来，如果去程回程都是 4837，那就是纯普通线，晚高峰要谨慎。还要小心一种单向 9929：只有去程是 9929、回程还是 4837，这种体验会打折。判断的唯一办法就是在 VPS 上实测回程 ASN，而不是只看商家宣传图。北方联通用户尤其适合认准 9929 回程，某些时段体验能和 GIA 掰手腕。

九、实战三：移动 CMI 和 CMIN2 怎么看

移动用户看两点：普通 CMI 是 AS58453，关键 IP 223.120.x.x；精品 CMIN2 是 AS58807，关键 IP 223.118 和 223.119。CMIN2 是移动在 2022 到 2023 年陆续上线的移动版 CN2 GIA，不和普通 CMI 共享带宽，晚高峰稳定、丢包常年低于 1%。很多商家宣传移动优化，其实只走了普通 CMI，也就是 AS58453，晚高峰照样丢包 3% 到 8%。

下单前在 VPS 上跑 nexttrace --fast-trace，看到移动回程出现 223.118 或 223.119 以及 AS58807，才是真 CMIN2。这里有个常见误区：有些人把 AS58453 直接叫成 CMIN2，这是不严谨的，AS58453 是普通 CMI，AS58807 才是精品 CMIN2。认准 ASN 才不会买错。移动宽带用户基数大，但长期被教程忽视，这篇文章就是专门把他们拉回视野。

十、常见骗局：假直连、单程 CN2、绕路欧美

用 NextTrace 最容易戳穿三种套路。第一，假直连：宣传三网直连，结果路由中途跳出 telia.net、cogentco.com 或者美国 IP，那就是绕了第三国，晚高峰必炸。第二，单程 CN2：去程漂亮地走了 59.43，回程却绕回 202.97 普通 163，体验直接打折一半。第三，拿 CN2 GT 当 CN2 GIA 卖：价格差两三倍，但你只看去程根本发现不了。

破解方法就一句：永远在 VPS 上跑 nexttrace 看回程 ASN，再配合晚上 9 点用 itdog 或 ping.chinaz 做全国多点测速，看丢包率。谁都骗不了你。另外，回程里如果任意一网中途跳出了 telia、cogent、level3 这类第三方国际中转，那就不是真直连，是假直连，直接pass。

常见热点问题解答 (FAQ)

NextTrace 必须装在 VPS 上才能测回程吗？

是的。回程是指从 VPS 传数据回你家的路径，必须在 VPS 里运行 nexttrace 指向你的家庭公网 IP 才能看到；在你自己电脑上跑只能看到去程，无法判断回程质量。

为什么我去程看到 219.158 却说是 9929 回程？

这叫非对称路由，去程走便宜的普通 4837、回程走精品 9929 是常见的高性价比搭配，下载流量占九成，所以回程才是关键，别被去程吓到。

59.43 开头的节点一定就是 CN2 GIA 吗？

不一定。59.43 说明经过了 CN2 节点，但如果中途又出现 202.97 这种 163 骨干，那就是 CN2 GT 或混合线路，全程优质才算真 GIA。

移动用户看到 AS58453 是不是就算优化了？

AS58453 只是普通 CMI，晚高峰仍可能丢包；真正移动精品是 AS58807，也就是 CMIN2，看到 223.118 或 223.119 以及 AS58807 才算优化到位。

一条命令能同时测三网吗？

可以，在 VPS 上执行 nexttrace --fast-trace 会一键测试电信、联通、移动、教育网的主要节点，最适合不想查测试 IP 的懒人快速判断。
