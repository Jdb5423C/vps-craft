Linux 最常用的 20 个基础命令：新手第一次登录该先学什么

2026-08-05动态实时复核有效2001 字6 分钟阅读
本篇评测核心结论与选购速览依据与适用条件见正文

刚拿到一台 VPS，面对黑乎乎的终端不知从哪下手？这篇文章把最常用、最该先记住的 20 个 Linux 命令按使用频率梳理清楚，并点出新手最容易踩的 5 个坑。

很多第一次买 VPS 的朋友，在控制面板点完「启动」之后，面对一个只有光标闪烁的黑色窗口会瞬间懵掉——这东西怎么用？其实 Linux 的世界看似高冷，真正日常用到的命令就那么二三十个，把它们记熟，你就能完成九成的管理工作。这篇文章不堆砌参数，而是按「先学哪十个、再学哪十个」的顺序，帮你建立第一张命令地图。

一、为什么先学命令，而不是先装桌面

在 Windows 或 macOS 上，你习惯用鼠标点图标；但在服务器领域，命令行是绝对主流。原因很简单：服务器通常没有图形界面，远程管理只能靠终端；而且一条命令能批量完成鼠标点几十次的操作。更重要的是，几乎所有运维脚本、教程、排错文档，都是以命令形式存在的。所以与其先纠结「怎么给 Linux 装桌面」，不如先花半小时把基础命令练顺——它会成为你日后所有 Linux 操作的地基。

二、第一批该记住的 10 个命令

我们对着一台刚登录的机器，最先要做的无非是「看看我在哪、看看里面有什么、建个文件」。对应的就是这十个：pwd 告诉你当前所在目录的绝对路径；ls 列出目录内容，加 -l 看详情、-a 看隐藏文件、-h 把大小变成人类可读；cd 切换目录，cd .. 回上层、cd ~ 回家目录、cd - 回到上一次所在目录；cat 把文件内容一口气打印出来；echo 把一段文字输出到屏幕或写进文件；mkdir 建目录，记得加 -p 才能一次建多层；touch 创建一个空文件，或者更新已有文件的时间戳；whoami 显示当前用户名；clear（或快捷键 Ctrl+L）清屏。这十个，建议今天就用虚拟机敲一遍，形成肌肉记忆。

三、复制、移动、删除三兄弟

接下来是文件操作的三兄弟。cp 负责复制，复制目录必须加 -r（递归），想保留权限和时间戳用 -a；mv 负责移动，其实它也兼职「重命名」，比如 mv old.txt new.txt；rm 负责删除，删目录同样要 -r，强制删除加 -f。这里必须划重点：rm -rf 是 Linux 里最危险的组合之一。现代系统对 rm -rf / 有 --preserve-root 保护，但你若手滑写成 rm -rf ~/* 或者路径多打一个空格，几秒内就能清空整个家目录且无法恢复。新手最稳妥的做法是给 rm 加个别名 alias rm='rm -i'，每次删除前先确认。

四、看不懂命令怎么办：man 与 --help

命令那么多参数，不可能全背下来。Linux 自带的帮助系统就是你的字典。man 是最权威的手册，比如 man ls 会打开 ls 的完整说明；很多人不知道 man 是分章节的，man 5 passwd 看的才是「passwd 这个文件格式」，而不是「passwd 命令」。另一个轻量方式是 --help，比如 ls --help 直接列出常用选项（注意这是 GNU 风格，部分 BSD 工具不支持）。遇到陌生命令，先 命令 --help 扫一眼，比到处搜博客快得多。

五、预览文件与盯日志：head / tail / less

服务器上最常做的另一件事是「看日志」。head 看文件开头，head -n 20 看前 20 行；tail 看结尾，而 tail -f 是运维神器——它能实时「跟随」文件末尾，新写入的日志会立刻滚出来，盯服务报错时全靠它。less 则是看大文件的正确姿势：less bigfile.log 打开后能用方向键翻页、按 /关键词 搜索、按 q 退出。切记别用 cat 去刷一个几个 G 的日志，那只会让屏幕瞬间被淹没。

六、我是谁、现在几点：whoami / date / history / which

几个顺手的小命令也值得记：whoami 确认当前身份（避免用错账户）；date 看系统时间，排查日志时间错乱时很有用，date +%Y-%m-%d 能按你要的格式输出；history 列出你敲过的命令历史，配合 ! 还能快速重跑（比如 !! 重复上一条、!123 跑第 123 条）；which 和 whereis 帮你定位某个程序装在哪，前者只看 PATH 里的可执行文件，后者还会带上手册和源码路径。

七、新手最常犯的 5 个错误

最后总结五个高频踩坑：第一，以为 ls 能看到所有文件，结果隐藏文件（以小数点开头）没看见，要用 ls -a；第二，路径里有空格却没加引号，shell 把空格当成参数分隔；第三，rm 忘了加 -r 去删目录直接报错；第四，用 echo 内容 > 文件 时把原本想「追加」的写成了「覆盖」，原内容瞬间没了（追加要用 >>）；第五，在错误的目录下执行了批量命令，影响了一堆不该动的文件。这些坑，几乎每个老手都踩过，提前知道能省下无数补救时间。

八、命令行之外：图形工具与学习路径

虽然命令行是服务器的绝对主流，但对纯新手来说，一开始完全丢掉鼠标确实会慌。其实现在有一批图形化工具能帮你平稳过渡：Windows 上可以用 PuTTY 或 MobaXterm 来管理 SSH 连接，macOS 自带终端就已经很好用，很多 VPS 厂商的控制面板也提供了网页版控制台。这些工具的价值在于降低初期的心理门槛，但我要提醒一句：它们只是「拐杖」，真正想用好 Linux，迟早得扔掉拐杖、直接在终端里敲命令，因为几乎所有的教程、脚本和排错思路都是面向命令行的。

那新手该去哪练手？我的建议是千万别拿生产服务器当试验田。你完全可以在自己电脑上装一个虚拟机（比如免费的 VirtualBox）跑一个 Linux，或者用 Windows 自带的 WSL2，它能给你一个近乎原生的 Linux 环境，文件互通、启动飞快，是 Windows 用户入门 Linux 最友好的方式。在本地随便折腾、随便删库，搞崩了重装就行，零成本零风险。

关于学习资料，网络上鱼龙混杂，我推荐几个公认的靠谱来源：系统自带的 man 手册永远是最权威的；中文社区里「鸟哥的 Linux 私房菜」至今仍是很多人的启蒙书；Arch Wiki 虽然面向 Arch 发行版，但大量条目对所有发行版都通用，是被全圈奉为神作的文档站；再有就是你所使用发行版的官方手册。比起收藏一百个视频，不如把 man 和官方文档翻熟。

最后给个实在的建议：建一个属于自己的命令笔记或者 cheat sheet。把今天学的命令、明天踩的坑、后天查到的巧用，都随手记下来——这比任何记忆法都管用，因为你记的是「自己真实用过的上下文」。如果能坚持每天只学透一个命令，三个月后你回头看，会发现自己已经能从容应付绝大多数日常运维场景了。

说到这里，其实命令行最迷人的地方不在于记住多少命令，而在于你开始用自动化的眼光看待重复劳动。等你把这些基础命令练熟，很多原本要鼠标点几十下的事，一行命令就解决了。保持好奇心，多敲多试，终端会慢慢从陌生变成你最顺手的工具，而这正是你 Linux 之路真正起步的地方。

常见热点问题解答 (FAQ)

记不住这么多命令怎么办？

不用背。先记住 pwd/ls/cd/cat 这一小撮，其余用到再查 --help 或 man；真正高频的命令敲多了自然就记住了。

rm 删掉的文件能恢复吗？

普通 rm 没有回收站，删除即不可逆。所以务必给 rm 设置 -i 别名确认，重要数据勤备份。

man 和 --help 哪个更好用？

--help 快、适合扫一眼选项；man 全面、适合深入理解，两者互补。

为什么我的 ls 看不到隐藏文件？

隐藏文件以小数点开头，默认不显示，加 -a 参数即可看到，比如配置文件 .bashrc。
