Hetzner 是谁？欧洲性价比之王

Hetzner 是德国老牌机房，在欧洲圈子里以「便宜到离谱」著称。它的 CX 系列共享 vCPU 云服务器，4GB 内存 + 40GB NVMe + 20TB 流量 月付只要 €4.51（约 ¥36）。同样配置放国内或香港，价格至少翻几倍。所以 Hetzner 的核心标签是：欧洲机房、超大流量、极低单价。

它适合谁？主要服务欧洲/全球用户的外贸站、API、爬虫、备份节点、开发测试；跑 Docker、Node、Python、Go、数据库的 ARM64 负载。不适合谁？核心用户在国内、要求回国快的人——Hetzner 没有中国大陆优化线路，国内访问很肉。这类需求请直接看 DMIT 或 野草云。一句话：Hetzner 是「欧洲本地神机」，不是「回国加速器」。

价格与套餐：€3.79 起，20TB 流量与 ARM 神车

Hetzner 2026 年在售真实价位（月付，支持按小时计费）：

  • CX11 入门：1 vCPU / 2GB / 20GB NVMe / 20TB，月付 €3.79（约 ¥29）。轻量博客、探针、测试。
  • CX22：2 vCPU / 4GB / 40GB NVMe / 20TB，月付 €4.51（约 ¥36）。最推荐的入门主力。
  • CX32：4 vCPU / 8GB / 80GB NVMe / 20TB，月付 €8.09。
  • CX42：8 vCPU / 16GB / 160GB NVMe / 20TB，月付 €19.52。
  • CX52：16 vCPU / 32GB / 320GB NVMe / 20TB，月付 €38.56。
  • CAX11 ARM（隐藏神车）：2 ARM vCPU / 4GB / 40GB NVMe / 20TB，月付 €3.79，比 x86 的 CX22 还便宜约 17%。
  • CAX41 ARM：16 ARM vCPU / 32GB / 320GB NVMe / 20TB，月付 €20.49，比 x86 CX52 便宜约 35%。
  • CCX13 专用 CPU：2 专用 vCPU / 8GB / 80GB NVMe / 20TB，月付 €13.65。独享核心，无邻居争抢。

整体 €4.51/月起（按题面口径），实际最便宜 €3.79。20TB 流量是全系标配，这点对大流量用户太友好了——做下载、做镜像、做备份同步都不用心疼流量。新用户官网/推荐活动还会赠约 €20 云额度（非优惠码），相当于首月白嫖，记得注册时顺手用上。很多人忽略 CAX（ARM）系列，其实它是「隐藏神车」：Ampere Altra ARM64 架构，同样 4GB/40GB NVMe/20TB 的 CAX11 月付 €3.79，比 x86 的 CX22（€4.51）还便宜约 17%；顶配 CAX41 比 CX52 便宜约 35%，能效还更高。前提是负载兼容 ARM64——Docker、Node、Python、Go、各类数据库基本都没问题，但老旧 x86 闭源程序可能跑不了。

线路与机房：欧洲强、回国弱，以及和 Vultr/DMIT 怎么选

Hetzner 的机房在德国（福克沙根、纽伦堡）和芬兰，欧洲及全球访问极快、延迟低。对做面向欧洲的外贸站、SaaS、游戏服来说，本地延迟可以压到个位数到二十几毫秒，体验拉满。这也是为什么那么多欧洲创业公司把生产环境放在 Hetzner。但必须诚实：它没有任何中国大陆优化线路，国内访问走普通国际出口，白天 200ms+，晚高峰容易拥塞丢包，体验远不如香港或 CN2 GIA 机器。

所以 Hetzner 的正确用法是「面向海外」。如果你硬要它回国加速，得自己套 CDN、做反代，成本反而上去了。想解锁流媒体、做回国隧道，还是 DMIT 的 CN2 GIA 更稳，原理见 什么是 CN2 GIA。这三家常被拿来比，但定位完全不同：Vultr 是「通用云」节点多、按小时灵活但无中国优化；DMIT 是「高端回国线」贵但三网稳；Hetzner 是「欧洲性价比王」便宜大碗但回国肉。服务欧洲选 Hetzner，服务国内要快选 DMIT，全球通用选 Vultr。常见组合是「Hetzner 做欧洲计算/存储 + DMIT 做回国中转/解锁」，或用 Hetzner 大带宽做备份同步、国内通过优化线路反代访问，长期成本最优。

后台、支付与「验证/押金」坑

Hetzner 的后台功能完整：快照、备份、防火墙、浮动 IP、私有网络都齐全，按小时计费也让它很灵活。系统模板丰富，Linux 主流发行版 + 自定义镜像都支持，还能挂卷、做负载均衡，工程化能力不输大厂。但支付和开户是它最劝退的地方：Hetzner 风控极严。新账号注册后常常要验证身份（上传证件、甚至视频验证），部分地区新用户可能被要求先充值或交押金才能开机器。

支付主要走信用卡/ PayPal/ 银行账户，对国人来说不如 野草云 的支付宝顺手。建议用真实信息注册，准备好证件，别用代理乱跳 IP，否则容易被封。这个门槛劝退了不少人，但也正因如此 Hetzner 的 IP 相对干净、被封锁概率低。FAQ：账号待验证多为风控，用真实资料 + 稳定 IP 基本过；部分地区需预充值/押金才能开机器，属正常流程。

缺点与谁该买、谁别买

缺点：

  • 回国线路差：无中国优化，国内访问慢、晚高峰易丢包，别指望裸连。
  • 开户严：需身份验证，部分要押金/预充值，国人操作成本高、周期长。
  • 支付不便：主用信用卡/银行账户，无支付宝，首次充值可能卡审核。
  • 不支持 Windows 授权简便购买：部分场景要自备，且 x86 才方便。
  • 工单时区：客服在欧洲时区，国内白天提问可能要等半夜才回。

该买的：面向欧洲/全球用户的外贸站、API 服务、爬虫集群、备份与同步节点、CI/CD、以及能跑 ARM64 的开发测试。这类用户闭眼入 CX22 或 CAX11，配合新用户云额度几乎零成本起步。Hetzner 是「海外部署的性价比天花板」。不该买的：核心用户在国内、要回国快、要免备案、不想折腾身份验证的人。这类请移步 野草云 香港、DMIT CN2 GIA，或对比 Vultr。做正经业务也要先接受它的开户门槛，别到时候卡在验证上误事。

套餐档位详细拆解：CX、CAX、CCX 怎么选

把 Hetzner 三大家族拆开看。CX 系列是共享 vCPU，按内存从 CX11（2GB/€3.79）到 CX52（32GB/€38.56），全系 20TB 流量、NVMe，性价比基准线，适合绝大多数通用负载。CAX 系列是 ARM64（Ampere Altra），同配置比 CX 再便宜 17%-35%：CAX11（4GB/€3.79）是隐藏神车，比 CX22 还便宜；CAX41（32GB/€20.49）比 CX52 省约 35%，能效更高。前提是你得兼容 ARM64——Docker、Node、Python、Go、主流数据库都没问题，老旧 x86 闭源二进制跑不了，选之前先确认。CCX 系列是专用 CPU（独享核心、无邻居争抢），CCX13（8GB/€13.65）适合稳定负载、编译、数据库这类怕抢资源的活。所以选购逻辑很简单：通用且兼容 ARM 就上 CAX 最省；不兼容 ARM 或要最稳的共享体验选 CX；要独享核心、零邻居干扰选 CCX。新用户记得领约 €20 云额度（官网/推荐活动，非优惠码），首月基本白嫖，配合 CAX11 几乎零成本起步。如果主要服务欧洲，闭眼 CX22/CAX11；要独享核心扛生产选 CCX13。

还有两点提醒：一是 Hetzner 的 20TB 流量是「入站免费、出站计费」的套路（实际按出站流量计，充足到几乎用不完），别被大数字吓到也别以为是无限；二是它的快照和备份是付费附加项但很便宜，重要机器一定开自动备份，配合按小时计费「试错即删」的玩法，长期持有成本极低。欧洲为王，把这几点吃透，Hetzner 基本没有坑。

新手开户小贴士

结论：Hetzner 值得买吗

非常值得——只要你用对场景。面向欧洲或全球用户的外贸、API、备份、开发测试，Hetzner 2026 年依然是性价比天花板，闭眼入 CX22 或 CAX11 都不会错，记得领新用户云额度。能上 ARM 就上 CAX，更省。但如果你核心用户在国内、要回国快、要免备案，Hetzner 给不了答案，请移步 野草云 香港、DMIT CN2 GIA，或对比 Vultr。做正经业务也要接受它的开户门槛。想横向看读 搬瓦工值得买吗。欧洲为王，回国靠边——这是用 Hetzner 的第一原则。

问：Hetzner 为什么被称为欧洲性价比之王？ 因为同样配置放国内/香港价格翻几倍。CX 系列共享 vCPU：4G 内存+40G NVMe+20TB 流量月付仅 €4.51（约 ¥36）。核心标签：欧洲机房、超大流量、极低单价。适合服务欧洲/全球用户的外贸站、API、爬虫、备份、开发测试，以及 ARM64 负载。
