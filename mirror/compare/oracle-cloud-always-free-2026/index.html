九、真实上手：用 Oracle 永久免费 ARM 搭个人博客的命令流

说一千道一万，上手最快。下面给你一套在 Oracle 永久免费 ARM 上从零到博客上线的命令流，复制粘贴即可（假设你已开好机器、拿到 root 和公网 IP）。全程 0元、不花钱，服务器本身来自 完全免费 的 Always Free。

ssh root@你的IP 登入后，先 apt update && apt -y upgrade 更新系统；新建普通用户 adduser deploy && usermod -aG sudo deploy，日常用它不是 root；装防火墙 apt -y install ufw && ufw allow 22,80,443/tcp && ufw enable。

apt -y install nginx && systemctl enable --now nginx。浏览器访问 IP，看到 Nginx 欢迎页就说明 Web 服务起来了——这一步你已经拥有一台 一直免费 的可视化服务器。

把域名 A 记录指向这台 IP（DNS 用 Cloudflare 完全免费 托管，顺带白嫖 CDN）。然后 apt -y install certbot python3-certbot-nginx，一条 certbot --nginx -d 你的域名 自动签发 Let's Encrypt 证书并配置好，续期全自动。HTTPS 也不用花钱。

用 rclone 把 /var/www 和数据库定时推到 Cloudflare R2 的 10GB 免费 空间（出站流量还免费），机器炸了秒恢复。这一步让 白嫖 也变得可靠。

装个 netdata 看面板，或写个 cron 探活脚本自动重启挂掉的服务。免费 ARM 的性能跑这些监控毫无压力。

常见热点问题解答 (FAQ)

「Oracle 永久免费是真的吗？」

是真的，Always Free 是 Oracle 官方的长期永久免费档，不是限时试用：含 ARM Ampere A1（2026年6月后新账户多为2核12G，老账户仍可能4核24G）、2台 AMD 微型机、200GB 块存储、10TB 月出口流量，以及 $300（30天）试用额度。只要不手滑开付费机型，这些资源一直免费、不会到期。

「0元 ARM 机器怎么领？」

注册 Oracle Cloud 账号（需实体卡验证身份，不真正扣费）→ 选好主区域（之后不可改）→ 进入 Compute 创建实例，机型选 Ampere A1 Flex、形状选 Always Free，配 200GB 内引导卷。热门区常提示 Out of capacity，可换冷门区或改用 OCI CLI/API 定时重试，直到成功开出一台免费 ARM 实例。

「2026 年还能开 4 核 24G 吗？」

不能，官方已正式执行减半新政。Oracle 已把新注册 Always Free 租户的 Ampere A1 免费额度全面调整为 2核12G（每月 1,500 OCPU 小时 / 9,000 GB 内存小时）。新账户只能开 2核12G（或拆分成两台 1核6G）；少数老账户若实例未被回收仍可保留历史 4核24G，但一旦删机重建就会被锁定在 2核12G 新上限。新号千万别强行按 4C24G 开机，否则超额部分会产生信用卡账单扣费！

「白嫖 Oracle 会扣费吗？」

免费档 本身不扣任何费：ARM、AMD 微型机、存储、流量都免费。唯一风险是你在控制台手滑创建了付费（PAYG）机型或加了超额块存储，才会从 $300（30天）试用额度里扣。另注意 Always Free 实例若连续7天 CPU、网络、内存利用率都低于20%会被回收。

「完全免费的服务器能建站吗？」

能建站，ARM 配 10TB 月出口流量足够跑个人博客、反向代理、Vaultwarden 等。但 Oracle 免费 IP 偶有被封锁或回收风险，稳定性不如付费 年付 VPS；商业站、长期生产环境建议用 RackNerd、CloudCone 等便宜年付 VPS 兜底，免费机只做学习或备线。
