一、为什么美国机房最容易做「不限量」

不是美国商家更慷慨，而是成本结构不一样。三个原因叠在一起，才让「1Gbps 不限流量」在美国变成了白菜价标配。

第一，转接带宽供给充足、竞争充分。美国本土有大量 Tier 1 运营商和公共交换中心，机房密度高，批发转接是充分竞争市场。商家买带宽的边际成本低，就敢把「不限量」写进套餐——反正卖的是端口，不是流量。相比之下，南美、非洲、部分亚太地区的国际带宽贵出一个量级，同样玩法跑不通。

第二，批发型机房多，商家不必自建网络。达拉斯、芝加哥、堪萨斯城、亚特兰大这些二线市场，电力便宜、机房供给过剩，大量 carrier-neutral 的批发机房可以只租机柜和转接。这里要澄清一个常见说法：口语里的「Tier 3 机房」通常指按 Uptime Institute Tier III 设计标准建造的数据中心（特征是「可并行维护」，不是「第三档次」），并不是等级排名。这类机房多了，小商家也能用很低的固定成本开出「大端口不限量」的产品。

第三，价格高度透明，卷得厉害。LowEndTalk 之类的社区把报价摊在阳光下，同城同配置谁贵谁难卖。结果是美国出现了一批「年付十几美元、1Gbps 口、几 TB 流量」的机型，以及「月付几美元、真 Unmetered」的切片机。你在欧洲很难找到同等密度的供给。

但要把话说全：不限量卖的是「端口 + 平均利用率」，不是「保证你一直满速」。商家赌的是大多数用户平均只用到端口的一小部分。所以只要出现持续打满，FUP（公平使用政策）一定会介入，区别只是「限速」还是「请你走」。这一点在美国和欧洲没有本质不同，只是美国因为端口大，触发阈值的绝对值更高。

二、五个主流机房：谁离中国近，谁更适合欧美

美国不是「一个机房」，选错海岸等于白花钱。下面五个是中文用户最常接触的落点，定位差别很大。

机房常见商家与产品到中国大陆的相对位置最适合谁
洛杉矶DMIT LAX（CN2 GIA / AS9929 / CMIN2 / Tier 1 四条线）、CloudCone（Multacom、DC4）、RackNerd DC02/DC03美西主力，回国优化线路资源最集中面向大陆用户的站点、API、远程办公、需要中转落地的业务
圣何塞RackNerd 圣何塞、DMIT SJC Lite（AS4837 标准路由，10Gbps 口）比洛杉矶略靠北，普通线路为主要大端口低价、对回国优化要求不极致的下载/备份
达拉斯RackNerd 达拉斯、大量独立服务器商家中部，回国普遍绕，晚高峰更看运气美中/拉美/欧洲均衡业务、成本敏感型后端
纽约BuyVM 纽约、RackNerd 纽约美东，跨大西洋最好，回国最远欧美用户为主、跨境电商、面向欧洲的 API

几条经验：回国优先美西，欧美业务优先美东，成本优先中部。洛杉矶之所以贵，是因为它同时满足「美西」和「优化线路供给多」；达拉斯之所以便宜，是因为它两边都不靠。还有一个常被忽略的点：同一个商家在洛杉矶的不同机房，线路可能完全不同——RackNerd 的 DC02 是普通线路，DC05 走的是高防网络，买之前一定确认具体 DC 编号，而不是只看「洛杉矶」三个字。

三、1Gbps 与 10Gbps，共享口与保证带宽，差在哪

这是美国不限量市场里水最深的一段。很多页面写「10Gbps 带宽」，实际含义可能只是「网卡是 10G，上联共享」，和你晚高峰能跑多少没有必然关系。

端口速率是包转发能力，不是承诺带宽。1Gbps 口的物理上限约为 125MB/s，这是天花板；10Gbps 口理论上限约为 1.25GB/s。但单线程 TCP 能不能跑满，还取决于往返时延和窗口大小——跨太平洋的高时延链路上，单线程往往跑不到端口上限，多线程、多用户并发才吃得下大端口。所以「10G 口」对下载站、CDN 回源、多用户并发有意义，对一个人 SSH 毫无意义。

共享口和独享口的区别，在邻居。共享 1Gbps 意味着你和同一台宿主机（甚至同一个上联）的人分这条管子；独享或「保证带宽」意味着这条管子只算你的。OVHcloud 美国站是目前少见的、在低价 VPS 上明示「保证带宽」的商家：VPS-1 到 VPS-4 分别标 500Mbps、1Gbps、2Gbps、3Gbps，并且全系 Unlimited traffic。BuyVM 的切片默认 1Gbps、标 Unmetered，官方页面把「Unmetered」和端口写在一起，属于比较诚实的写法；社区资料称季付或月付满三个月后可申请升级到 10Gbps，具体条件以商家页面和工单为准。

10G 到底值多少钱？LowEndTalk 上一家美国商家 2026 年的公开报价是：1Gbps 不限量为基础款，2Gbps 每月 99 美元、3Gbps 190 美元、5Gbps 350 美元、10Gbps 599 美元，且注明是「100% 独享端口、含 DDoS 防护」。这组数字很能说明问题：真正的独享 10G 端口，月成本在几百美元量级。所以当一台月付几美元的 VPS 写「10Gbps」时，它几乎一定是共享口，或者是「可申请升级的端口能力」，不是「保证给你 10G 的国际带宽」。

端口档位常见形态现实吞吐适合的场景
100Mbps 共享低价清库存机型、老款套餐百兆级，晚高峰容易塌探针、监控、轻量代理、个人博客
1Gbps 共享美国不限量 VPS 的主流形态空闲时接近千兆，高峰看邻居中小下载站、网盘中转、备份同步
1Gbps 保证 / 独享OVH 美国站等明示保证带宽的产品相对稳定，不受同机邻居影响对流媒体分发、API 有稳定性要求的业务
10Gbps 共享大端口 VPS、部分高配切片峰值高但波动大，取决于上联收敛比多用户并发下载、CDN 边缘回源
10Gbps 独享独立服务器或高防专线，月费数百美元可长期跑满，需自备足够 CPU 与磁盘商业下载站、视频分发、大型游戏后端

判断共享还是独享，最实际的办法有三条：读 TOS 里对「port」和「guaranteed bandwidth」的表述；问工单要一句书面确认；在晚高峰用多线程 iperf3 复测，看是否稳定在标称值的一个合理比例。三样都对不上，就按共享口预期。

四、抗 DDoS：OVH、BuyVM、RackNerd、DMIT、CloudCone 各自能做到什么

先把概念拆开：DDoS 防护通常分网络层（L3/L4，流量清洗）、传输层和应用层（L7，CC 攻击）。VPS 商家送的绝大多数是前三层的清洗，应用层要靠 CDN、WAF 和自己限速。把「有高防」理解成「网站不会挂」，是最常见的误判。

  • OVHcloud：全系 VPS 自带 Anti-DDoS，官方写明「持续防护、自动缓解、对服务无影响」，不额外收费。体量是它的优势——清洗在骨干侧完成，适合游戏服、长期被盯的业务。缺点是默认防护面向通用攻击，遇到大流量应用层攻击仍要自己加 WAF。
  • BuyVM：防护是可选加购，官方标价每受保护 IP 每月 3 美元，池化清洗能力标称 500+ Gbps、700+ Mpps，覆盖 L4 到 L7。好处是「平时不买也能开机」，坏处是攻击来得突然时再下单，IP 可能已经被 null route。做游戏服或长期被打的站，建议开机就买。
  • RackNerd：常规特价机在页面上只强调 1Gbps 端口与 ctrl 面板防火墙，并没有承诺高防；高防是另一条产品线（社区资料指向洛杉矶 DC05 的 Protected Network，标称最高 60Gbps 级别），需要单独选购。把 21.99 美元年付机当高防用，是典型的错配。
  • DMIT：自营网络，官网标 7.6Tbps Tier 1 骨干、洛杉矶节点 3.8Tbps 接入容量，主要卖点是回国路由而非「清洗规格」。防护能力会随产品线变化，下单前用开工单问清楚「这个套餐被打时怎么处理、是否 null route、是否有清洗阈值」。
  • CloudCone：官方写明每个云服务器含 Voxility 驱动的按需网络层 DDoS 防护，免费。属于「有基础防护、够挡常见扫描和中小攻击」的水平，不要指望它扛持续大流量。

再补三条现实规则：一，被打到超过清洗能力，商家的标准动作是 null route（把 IP 黑洞掉），你的服务照样中断；二，换 IP 通常要钱，CloudCone、BuyVM 等都有明确的换 IP 政策；三，真正的业务连续性靠「CDN 隐藏源站 + 多 IP + 限速」，而不是赌某一家清洗容量。

五、回国线路：CN2 GIA、AS9929、CMIN2、AS4837 分别是什么体验

这一节是给「人在国内、机器在美国」的读者准备的。先记住一句话：端口决定峰值，线路决定你能不能接近峰值。一台 1Gbps 走 163 骨干的机器，晚高峰实际下行可能只有几十兆；一台 100Mbps 走 CN2 GIA 的机器，反而能稳稳跑满。

线路AS 号与识别特征谁最受益体验与成本
CN2 GIAAS4809，国内段 59.43 开头，全程不落 202.97电信用户，以及对稳定性要求最高的业务晚高峰最稳、抖动最小，价格系数最高；DMIT、搬瓦工是典型供给方
AS9929（CUII/CUG）AS9929，国内节点常见 218.105、210.51 开头联通用户联通自有精品网，负载低，体验接近 GIA，价格通常是 GIA 的六七成

AS4837AS4837（联通 169），节点 219.158 开头预算敏感、非实时业务最便宜的一档，白天够用，晚高峰波动明显

还有两个坑要单独说。CN2 GT 不是 CN2 GIA：GT 只有国际段走 CN2，国内段回落到 163 骨干，路由里会看到 202.97，价格便宜但晚高峰照样堵。判断方法很机械——回程 MTR 里出现 59.43 且没有 202.97，才算真 GIA。「三网优化」也不是一句口号：真正的三网精品是电信 CN2 GIA + 联通 AS9929 + 移动 CMIN2 各回各家，DMIT 的 Premium 与 Eyeball 两条线就是按这个思路分的，买之前看清是「三网全精品」还是「只优化其中一家」。

美国不限量机怎么配中转？主流有三种架构：

  1. 落地 + 中转（最常用）：美国大端口不限量机做落地，负责存储和出流量；再买一台靠近用户的 CN2 GIA / AS9929 小带宽机器做中转，两者用 WireGuard 或 GRE 组内网，用户连中转。优点是回国体验好、落地机可以随便换；缺点是中转带宽就是新瓶颈，100Mbps 中转后面挂 1Gbps 落地，最终体验仍是 100Mbps，而且中转机流量通常按 GB 计费，成本要重算。
  2. 反代 / 回源：中转机上用 Nginx stream 或 HAProxy 做四层转发，适合建站、API、固定端口服务；比隧道好排查，但加密要自己补。
  3. CDN 回源：静态资源和大文件交给 CDN，源站只出动态请求。这是最省钱的「伪不限量」，也是绝大多数博客和下载站该走的路。

务实建议：先确定用户主要在哪个运营商，再选线路，不要反过来。电信用户买 GIA、联通用户买 9929、移动用户买 CMIN2，混着买等于为不需要的优化付钱。中转方案只用于自有版权内容与合规业务，不要拿它做侵权分发，AUP 比 FUP 狠得多。

八、采购清单：下单前要核对的八件事

  1. 先月付，再年付。美国商家年付折扣大，但退款政策普遍不友好，促销款多为不可退。
  2. 确认 DC 编号，不只确认城市。同一商家不同机房的线路、防护、甚至 IP 段质量都不同。
  3. 读三行字：端口、FUP、超额处置。是限速、null route，还是按 GB 计费，差别巨大。
  4. 晚高峰跑三网 MTR。晚八点到十一点，电信/联通/移动各一条，看回程是否落 202.97。
  5. 确认是共享口还是保证带宽。要一句书面回复，不要只看宣传图。
  6. 问清防护与换 IP 政策。被打时是否 null route、换 IP 多少钱、多久生效。
  7. 算清续费价。首年特价、续费恢复原价的套路在美国同样存在。
  8. 做好备份与监控。不限量机被限速或关停时，数据还在才叫事故可控。

最后给一个心态建议：美国不限量市场的供给很充分，没有「唯一正确答案」，只有「这个价位下最合适的组合」。缺货就等补货，别找代购加价；涨价就换一家，别为情怀续费。把端口、线路、防护、价格四个变量列成表，答案通常自己就浮出来了。

常见热点问题解答 (FAQ)

美国的不限流量 VPS 真的完全不限吗？

不是。它承诺的是「不按 GB 计费」，但一定同时受两个约束：端口速率（1Gbps 口的物理上限约 125MB/s）和 FUP（持续打满会被限速或要求整改）。BuyVM 这类写 Unmetered 的商家相对诚实，会把端口写在套餐里；写 Unlimited 的则要看 TOS 细则。正确理解是「不产生超额账单」，不是「永远满速」。

1Gbps 和 10Gbps 端口，实际体验差多少？

取决于你的业务形态。单线程跨太平洋传输受时延和 TCP 窗口限制，往往吃不满 1Gbps，换 10Gbps 口也不会变成 10 倍；但多用户并发、CDN 回源、大文件分发这类场景，大端口能明显减少排队。另外要分清「端口能力」和「保证带宽」——月付几美元标 10Gbps 的基本是共享口，真正的独享 10G 在公开报价里是每月数百美元级别。

回国一定要买 CN2 GIA 吗？

看你的用户用什么宽带。电信用户优先 CN2 GIA，联通用户优先 AS9929，移动用户优先 CMIN2，按运营商匹配比盲目上 GIA 更划算。如果业务对晚高峰不敏感（备份、定时任务、静态站），AS4837 配合 CDN 完全够用，没必要为 GIA 付两三倍溢价。

OVH、BuyVM、RackNerd、DMIT 谁抗 D 更强？

按「默认包含」排序是 OVH 最省心（全系自带、自动缓解、不另收费）；按「可加购的清洗规模」看 BuyVM 的池化能力标称较高（500+ Gbps / 700+ Mpps，每 IP 每月 3 美元）；RackNerd 常规特价机不承诺高防，高防要另买 DC05 产品线；DMIT 卖点是回国路由，防护规格要开工单确认。没有一家能保证「永不被黑洞」，业务连续性要靠 CDN 与多 IP。

美国机和欧洲机怎么选？

用户在中国或亚太选美西，用户在欧美选欧洲，纯备份比每 GB 单价。价格上两家入门档接近（OVH 美国站 4.54 美元/月起、欧洲站 3.50 欧元/月起），真正拉开差距的是延迟与 FUP 口径。支付方面美国商家支持支付宝的更普遍，欧洲商家多以信用卡、PayPal、SEPA 为主。

可以用美国不限量机做下载站或流媒体中转吗？

自有版权、开源镜像、授权内容可以，侵权内容不行。美国商家普遍执行 DMCA，欧洲商家还会叠加本地法律要求；一旦被投诉，标准处置是关停且不退款。另外持续打满端口会触发 FUP 限速，建议把负载控制在端口的六七成，长期稳定比瞬间跑满更划算。
