一、三种重装方式总览：先选对的路

在动手前先搞清楚你手里有哪几张牌，因为不同虚拟化、不同面板支持的方式不一样：

  • 面板一键重装（Reinstall / Rebuild）：最稳、最推荐。KVM 架构的机器，只要商家在 SolusVM、Virtualizor 或自研面板里提供了系统模板，登录面板点几下就能重装，底层分区、引导、驱动全由商家处理好，几分钟搞定，IP 不变。
  • DD 一键脚本（网络重装）：当面板模板不够用（比如想装更新版本的 Debian，或者想要一个完全去 bloat 的纯净系统），就在 SSH 里跑一行脚本，让它从网络下载镜像把整块盘重写。灵活但风险高，必须 root、必须 KVM，OpenVZ 跑不了。
  • ISO 挂载 / 救援模式：最硬核。面板支持自定义 ISO 的（如 Vultr），可以挂 SystemRescue、Finnix 这类救援盘修系统，或者挂官方 ISO 自己从零装。机器起不来、GRUB 写坏了、要换 Windows，基本都靠它。

一句话：能面板重装就别 DD，能 DD 就别挂 ISO——越往后越自由，也越容易翻车。

二、面板一键重装：SolusVM 与 Virtualizor 实操

预算 VPS 里最常见的面板就是 SolusVM（RackNerd、ColoCrossing 系几乎都用它）和 Virtualizor（很多印度/东南亚主机商在用）。两者的重装逻辑几乎一样：都是进面板 → 找 Reinstall → 选系统 → 确认。

1. SolusVM 一键重装（以 RackNerd / ColoCrossing 为例）

RackNerd 和母公司 ColoCrossing 的 KVM VPS 全部走 SolusVM 面板，2026 年它在面板里内置了 CentOS、Rocky Linux、AlmaLinux、Fedora、Debian、Ubuntu 等 10 多个官方模板，洛杉矶、圣何塞、西雅图、达拉斯、芝加哥、纽约、阿什本等机房通用。具体步骤：

  1. 登录 SolusVM 控制面板（欢迎邮件里有地址，端口一般是 5656 之类）。
  2. 如果名下有多台机器，先在 Virtual Servers 列表里选中要重装的那一台，核对主机名/IP，别选错机器。
  3. 在管理页往下滚，找到 Reinstall 按钮并点击。
  4. 在下拉里挑你要的操作系统模板，比如想换 Debian 12 就选它。
  5. 滚到页面底部再点一次 Reinstall，弹窗点 Yes 确认。系统会提示重装最多需要约 10 分钟，并给出一个新的 root 密码。
  6. 务必把面板显示的新 root 密码抄下来，重装完成后用 SSH 连上去第一件事就是改密码。

注意：SolusVM 的重装只装最小化基础系统，不会自带 cPanel / 宝塔之类的面板，应用要你自己装。另外 SolusVM 还有独立的 Root/Admin Password 标签页，可以在不重装的情况下单独改 root 密码，机器卡在某个状态又登不进去时很好用。

2. Virtualizor 与其他自研面板

Virtualizor 面板的重装入口一般在 VPS 管理页的 Reinstall 或 OS Reload 标签，流程同样是选模板 → 设密码 → 确认。CloudCone 则用的是自家云面板（不是 Virtualizor），入口叫 Rebuild：进实例管理页，左侧点 Rebuild，在下拉里选系统，点 Re-install，弹窗确认 Yes 后大约 40 秒就装好，新登录信息会发到你注册邮箱。CloudCone 的 1GB 年付套餐（1 核、30GB SSD、5TB 流量）就是走这条路径，年付约 15 美元起，纯 KVM + SSD RAID10。

三、常用 DD 一键脚本实战

DD 本质是“用 dd 把网络镜像整盘写入硬盘”。社区脚本帮你把下载镜像、改 GRUB、重启进内存安装这些脏活全自动化了，你只要一行命令。下面三个是 2026 年还在维护、口碑最稳的。

方案 A：leitbogioro（doge / Vicer 续维护版）——最推荐

这个脚本由 Vicer 原始版演化而来，目前由 leitbogioro 维护，支持 Debian / Ubuntu / AlmaLinux / Rocky / Fedora / Alpine / Windows，还能自定义端口、主机名、时区、虚拟内存，真正“开箱即用”。前置先装 wget：

BASH 
sudo -s
cd ~
apt update -y && apt install wget -y
# 或 RedHat 系：
# dnf install wget -y
wget --no-check-certificate -qO InstallNET.sh 'https://raw.githubusercontent.com/leitbogioro/Tools/master/Linux_reinstall/InstallNET.sh' && chmod a+x InstallNET.sh

最常用的纯净 Debian 12 一键（密码自己设）：

BASH 
bash InstallNET.sh -debian 12 -pwd 'YourStrongPassw0rd'

更完整的参数示例，把端口、主机名、时区、SWAP 一次设好：

BASH 
bash InstallNET.sh -debian 12 -pwd 'YourStrongPassw0rd' -port '58222' -hostname 'mjj' -timezone 'Asia/Shanghai' -swap '1024'

换 Ubuntu 22.04 就把 -debian 12 换成 -ubuntu 22.04；想装 Windows 用 -windows。默认 Linux 用户是 root，默认密码 LeitboGi0ro，Windows 用户 Administrator、密码 Teddysun.com——所以装完必须立刻改密码或换密钥登录。

方案 B：MoeClub 原版 DD 脚本

萌咖（MoeClub / Vicer）的脚本更偏“装指定版本 Debian”，语法稍微不同，用 -d 指定大版本、-v 指定位数、-p 设密码：

BASH 
bash <(wget --no-check-certificate -qO- 'https://raw.githubusercontent.com/MoeClub/Note/master/Debian/dd_debian.sh') -d 12 -v 64 -p 'YourStrongPassw0rd'

老版本写法（从 moeclub.org 附件拉）：

BASH 
wget --no-check-certificate -qO InstallNET.sh 'https://moeclub.org/attachment/LinuxShell/InstallNET.sh' && bash InstallNET.sh -d 11 -v 64 -a -firmware

想 DD 一个自定义的第三方镜像（比如某精简版），用 --image 指定 .gz/.xz 的直链即可，但要注意镜像来源必须可信，不明 img 可能带后门。

方案 C：通用网络重装脚本（vpsaff 系）

还有一个带图形化交互的通用脚本，适合不想记参数的新手，跑起来后用方向键选系统：

BASH 
wget -N --no-check-certificate https://down.vpsaff.net/linux/dd/network-reinstall-os.sh && chmod +x network-reinstall-os.sh && ./network-reinstall-os.sh

DD 的共性注意点：重装过程会断开 SSH，耐心等 5 到 20 分钟，期间可以用 ping 你的IP 看是否重新通了；若脚本用了非 22 端口，记得先在商家防火墙/安全组放行该端口，否则装完必失联；DD 不要在原本是 CentOS 6/7 的老环境上硬刚，建议先在面板重装成 Debian 11/12 再跑脚本，成功率更高。

四、挂载 ISO 与救援模式（rescue mode）

当面板模板和 DD 都救不了你——比如 GRUB 写坏进不了系统、要把磁盘文件系统修好、要装面板列表里没有的 FreeBSD/OpenBSD、或者要挂官方原版 ISO 自己分区——就需要 ISO 挂载和救援模式。

Vultr 的 Custom ISO 与救援盘

Vultr 的面板没有传统“重装”下拉，但它给你更底层的控制：在 Server 的 Settings → Custom ISO 里，可以从官方 ISO 库挑（Finnix、SystemRescue x64 等），也能上传或填 URL 挂自己的 ISO，点 Attach ISO and Reboot 就会从光盘启动。官方文档里把 Finnix / SystemRescue 当作标准救援盘来用：

SHELL / COMMAND 
# 进入 SystemRescue 后设 root 密码并开 SSH
passwd
# 系统会自动启动 sshd，之后就能用 SSH 连进救援环境
# 先看磁盘设备名
lsblk
# 修文件系统（务必先确认磁盘未挂载）
fsck -f /dev/vda1
# 想直接翻文件就挂载
mount /dev/vda1 /mnt

提示：Finnix 启动后超过 60 秒不操作会自动回退到原系统，卡住时点控制台右上角的 Send CtrlAltDel 重新进 ISO；SystemRescue 则不会自动回退，适合慢慢修。修完记得在面板里 Detach ISO 再重启。

救援模式最常见的两个场景：一是 kernel panic 后挂载 ISO、chroot 进原系统把坏掉的 /etc/default/grub 改回来；二是磁盘爆满 / 误删系统文件，挂救援盘把重要数据 scp 出来再重装。

五、更换 Linux 发行版与去 bloat 纯净系统

很多人重装就是为了“换发行版”。从 CentOS 换到 Debian/Ubuntu 是 2026 年的主流走向，因为传统 CentOS Linux 已被 Red Hat 停掉，社区基本只认 Debian 系做建站。换发行版有两种姿势：

  • 面板直接选：如果目标发行版在面板模板里（Debian 12、Ubuntu 24.04、AlmaLinux 9、Rocky 9 等），直接 Reinstall 选它最省事，驱动和云初始化都帮你配好。
  • DD 装更新/更纯的版本：面板模板落后时，用 leitbogioro 脚本 DD 一个最新的 Debian 12，得到的是几乎零预装、零监控代理的纯净系统，特别适合多台机器统一环境。

“去 bloat”还有一层意思：某些商家镜像会预装监控 agent、优化脚本甚至未知服务。DD 之后第一件事跑 systemctl list-units --type=service 看看哪些服务在跑，不认识的就 systemctl disable --now 服务名 关掉。RackNerd、CloudCone 这类主流商家一般给的是干净最小化镜像，但小厂镜像建议 DD 一遍更安心。

六、重装后必跑的基础安全初始化命令

无论你用哪种方式重装，新系统上线第一件事绝不是立刻部署业务，而是把安全底座打好。下面这套命令在 Debian/Ubuntu 上通用，按顺序跑：

SYSTEMD 
# 1. 更新系统
apt update && apt upgrade -y

# 2. 新建一个普通用户并授予 sudo
adduser deploy
usermod -aG sudo deploy

# 3. 给新用户配 SSH 公钥登录（在本机执行 ssh-copy-id）
# ssh-copy-id deploy@你的IP

# 4. 关闭 root 密码登录、只允许密钥
sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin prohibit-password/' /etc/ssh/sshd_config
sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
systemctl restart sshd

# 5. 开防火墙，先放行 SSH 端口再 enable，避免把自己锁外面
ufw allow 58222/tcp
ufw enable

# 6. 安装 fail2ban 防爆破
apt install -y fail2ban
systemctl enable --now fail2ban

# 7. 设主机名与时区
hostnamectl set-hostname mjj
timedatectl set-timezone Asia/Shanghai

# 8. 打开自动安全更新
apt install -y unattended-upgrades
dpkg-reconfigure -plow unattended-upgrades

如果你习惯用脚本里的自定义端口（比如上面的 58222），记得第 5 步放行的是同一个端口，且 sshd_config 里的 Port 也要改成它。改完用新用户新端口另开一个 SSH 会话测试能登录，再关掉旧会话，确认无误才算收工。

常见热点问题解答 (FAQ)

重装系统会换 IP 吗？

不会。SolusVM、Virtualizor、CloudCone、Vultr 的一键重装都保留原有 IPv4，只有你主动销毁再重建机器才会换 IP。

DD 脚本和面板重装哪个更安全？

面板重装最安全，底层分区和驱动由商家保证；DD 脚本来自第三方，务必只用 MoeClub、leitbogioro 等可信源，且别在重要生产机上拿不明镜像乱 DD。

OpenVZ 机器能 DD 吗？

不能。DD 和自定义内核都要求 KVM 等全虚拟化；OpenVZ 共享宿主机内核，只能靠面板提供的有限模板重装。

重装后连不上去怎么办？

先确认防火墙/安全组放行了 SSH 端口，再用商家网页 VNC/Console 看启动日志；若 GRUB 写坏就挂救援 ISO 进 chroot 修。

CloudCone 和 RackNerd 重装有次数限制吗？

面板一键重装一般不限次数，但每次都会清空数据；RackNerd 自定义 ISO 需工单且可能被拒，所以日常重装优先用面板模板。
