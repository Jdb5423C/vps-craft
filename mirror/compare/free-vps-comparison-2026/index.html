三、“永久免费”与“限时试用”的本质差异：谨防信用卡被划扣

玩转免费云服务器，第一条铁律是区分两类完全不同的产品形态：

  1. 永久免费（Always Free / Perpetual Free）：
    代表为 Oracle Cloud Always Free 与 AWS 的 CloudFront/Lambda。只要您的账户保持正常状态，且分配的资源总量严格位于免费额度包之内，官方系统在出账日永远出具 $0.00 账单，永不过期。
  2. 限时免费套餐（12-Month Free / Limited Credit）：
    代表为 AWS 12-Month Free 与 Azure。这类服务在注册后的第 365 天终止免费期。到了第 366 天，系统绝不会自动关机，而是立刻自动转入标准按需计费（On-Demand），直接无感划扣您预留的信用卡！新手必须在日历上设立提醒，在到期前 7 天彻底 Terminate 实例并删除卷。

四、免费云三大核心痛点与避坑自救指南

1. 信用卡注册与风控破局（针对 Oracle ABC 错误）

在注册 Oracle 或 AWS 时，大量国内用户遭遇“无法完成您的交易 / Error processing transaction”。破局核心原则如下：

  • 卡片类型：必须使用带有 Visa / MasterCard 标识的正规银行双币或全币种实体信用卡（如招商银行、中信银行、中国银行单标卡）。虚拟信用卡（如 Depay、OneKey）99% 会被风控系统直接拉黑；
  • 网络与账单一致性：注册时切勿使用数据中心代理或公网机房 IP，推荐使用国内本地宽带直连，填报的账单地址必须使用与信用卡在银行预留完全一致的中文拼音。
  • 进阶破局：详见站内专栏 【甲骨文系列 03】甲骨文注册终极邪修大法：针对 ABC 错误与同一实体卡复用的破局实战。

2. 甲骨文闲置实例防回收优雅保活

甲骨文官方文档明确规定：如果 Always Free 计算实例在连续 7 天内，其 CPU 利用率（95 百分位）、内存利用率及网络使用率同时低于 20%，系统判定其实例处于闲置（Idle）状态，并有权自动将其关机甚至终止释放卷！

  • 严禁暴力挖矿脚本：很多新手在网上找所谓的“CPU 占用脚本”，把 CPU 持续拉到 100%，这极易被甲骨文后台安全扫描判定为滥用（Abuse）而直接封停整个租户！
  • 优雅保活正道：推荐使用 lookbusy 工具模拟 25% 左右的周期性平滑负载，或者部署真实常驻业务（如个人网盘、Docker 编译节点、Uptime Kuma 监控服务）。详见 【甲骨文系列 04】拒绝封号与关机：Oracle 官方闲置回收规则深度解读与优雅保活姿势。

3. AWS IPv4 独立收费与预算告警金钟罩

由于 AWS 自 2024 年 2 月起对公网 IPv4 按 $0.005/小时计费，玩 AWS 免费套餐必须建立两道防御机制：

  • 只保持一台带公网 IP 的 EC2 处于运行中（Running），切勿创建第二台，且千万不要解绑或闲置弹性 IP（Elastic IP）；
  • 立即在 AWS Budgets 中配置一个 $0.01 美元的预算告警，只要产生哪怕一分钱的费用，系统便会第一时间发送邮件通知。详见 【2026 最新】AWS 免费套餐终极避坑与零元实战指南。
