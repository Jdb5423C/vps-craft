一、先说结论：搬瓦工没有 0 元套餐

如果你在 Google 或论坛里看到「搬瓦工 0 元 bug 价」「0 元购搬瓦工」这类说法，可以直接给结论：BandwagonHost 官方没有任何 0 元套餐，也没有可以长期白嫖的免费方案。它的入门方案是 20G KVM PROMO，$49.99/年，配置为 2 核 / 1GB 内存 / 20GB SSD / 1TB 月流量 / 1Gbps 带宽；这个价位常年缺货，补货后也很快售罄。

搬瓦工历史上确实出现过更低的年付方案（例如 $29.99/年 的早期限量版），但那是 2019 年之前的产品线，早已下架且无法续费。2026 年你在官网上能看到的最低价格，就是 $49.99/年 这一档；再往下没有隐藏的「0 元入口」，也没有可以靠优惠码把价格打到 0 的漏洞。

那为什么「0 元 bug 价」会传得这么广？我们核查了三类最常见的来源，并逐条给出事实。

二、三类「0 元 bug 价」传言逐一核查

1. 限量版补货被误读成「0 元」

搬瓦工近几年最主要的促销形式，是限量版套餐补货，而不是直接打折。典型代表包括：

  • 传家宝 CN2 GIA-E 10G 限量版：1 核 / 512MB / 10GB SSD / 500GB 月流量，历史价格约 $46.59/年（使用优惠码后）；
  • THE PLAN 系列：2 核 / 2GB / 40GB SSD / 1TB 月流量，季付 $29、年付 $99；
  • BIGGERBOX / POWERBOX / SAKURABOX / MEGABOX-PRO / Tokyo Plan v2 等：不同年份、不同机房的限量款，价格从几十美元到上百美元不等。

这些套餐的共性是：库存极少、补货时间不固定、上架后几分钟到几小时内售罄。抢不到的人会在论坛里说「又错过了」「跟 0 元似的」，传着传着就变成了「搬瓦工 0 元 bug 价」。但实际付款页面显示的价格，最低也是 $46.59/年 这一档，不存在 0 元结算。

另外，限量版套餐本身已经是优惠价，不能用优惠码叠加。这一点在搬瓦工中文笔记的 NODESEEK2026 公告里写得很清楚：「限量版套餐本身已是优惠价，不支持使用优惠码」。

2. 优惠码叠加的误解

2026 年 2 月 18 日，搬瓦工放出了新的循环优惠码 NODESEEK2026，力度为 6.77%，适用于全场常规套餐（KVM、CN2 GIA-E、香港、东京、大阪等），新老用户均可使用，续费时自动应用同等折扣。

但它的限制同样明确：

  • 不能与限量版套餐叠加；
  • 每次购买只能使用一个优惠码；
  • 续费已有 VPS 时不能更换优惠码，续费价格取决于你购买时使用的那个码；
  • 官方没有承诺优惠码的长期有效期，随时可能失效。

算一笔账：$49.99/年 的 20G KVM，打 6.77% 折扣后约 $46.6/年，折合每月不到 $4。这已经是「正规渠道能拿到的最低价」，距离 0 元还差很远。任何声称「输入某个码直接免单」的说法，都不符合官方规则。

3. 第三方「0 元代购 / 共享账号」

还有一类「0 元」来自第三方：

  • 共享账号：几个人合用一个搬瓦工账号，号称「0 元上车」。这违反搬瓦工服务条款，账号随时可能被风控回收，且你的服务器、支付信息、SSH 密钥都与陌生人共享；
  • 0 元代购：以「帮你下单」为名，要求你提供账号密码或支付信息，常见于贴吧、闲鱼、Telegram 群；
  • 返利/试用骗局：承诺「先付后返」「0 元试用一年」，实际拿到钱就失联。

这类「0 元」不是 bug，是风险。搬瓦工官方支持支付宝、PayPal、信用卡付款，没有必要通过第三方代付；账号一旦共享，等于把服务器和数据交给陌生人。

MINIBOX、BIGGERBOX、The Amsterdam Plan 这几款在官方页面标注「Invite code required」。这意味着：

  • 商品页需要填入有效邀请码才能加入购物车，否则会提示不可用；
  • 邀请码由官方不定期发放，社区互相转赠，同一个码可能几小时后就失效；
  • 邀请码不是优惠码，不能用来打折，只是购买资格。

所以看到「搬瓦工 $29/年」的帖子却买不到，通常不是遇到了 bug，而是邀请码过期或该套餐已售罄。

3. 补货时间：没有日历，只有监控

  • 不定时上架：可能几个月不补，也可能一周补两次；
  • 库存极少：通常几十到几百台，热门机房几分钟内售罄；
  • 不承诺在线率：限量版官方写明「best effort service」，不提供 uptime 保证；
  • 不能叠加优惠码：限量版本身就是折扣价。

想提高抢到的概率，可以关注这些公开渠道（均为第三方社区，非官方）：

  • 补货监控站：如 vpsrestock 等库存实时查询站点，按分钟级刷新库存；

五、优惠码的正确用法（NODESEEK2026）

如果你要在常规套餐上省钱，正确姿势是：

  1. 进入搬瓦工官方下单页，选择目标套餐与计费周期；
  2. 在结算页找到「Promotional Code」输入框，填入 NODESEEK2026；
  3. 点击验证，确认总价出现 6.77% 折扣后再付款；
  4. 续费时系统会自动沿用购买时的优惠码，不需要也不允许更换。

几个常见误区：

  • 「先原价买，之后再补优惠码」：不行。优惠码只在购买时生效，续费也不能更换；
  • 「多个码叠加」：不行。每次购买只能用一个码；
  • 「限量版也能用」：不行。限量版本身已是优惠价；
  • 「优惠码永久有效」：官方没有承诺。BWHCGLUKKB 是 2024 年前后流通的 6.77% 码，2026 年公开渠道主推的是 NODESEEK2026；旧码是否仍可用，只能以下单页验证结果为准。

七、30 秒验证一个「bug 价」的真假

看到「搬瓦工 0 元」「1 折」「内部价」这类标题，按下面的顺序检查一遍，基本不会踩坑：

  1. 看域名：只在 bandwagonhost.com 结账。页面底部应能看到 IT7 Networks Inc. 与 AS25820；域名不对、页面是镜像复制的，一律当作钓鱼站。
  2. 看套餐是否存在：在官方「全部方案」页搜套餐名。搜不到的名字，不管帖子写得多详细，都是编的。
  3. 看结账金额：在 Promotional Code 里输入优惠码并点验证，总价必须当场变化。任何「先付款，找客服改价」的说法都是骗局。
  4. 看是否需要你交账号：官方从不需要你提供后台密码、邮箱密码或验证码。要求代登录、代下单、代付的，直接拒绝。
  5. 看价格是否低于成本：$29/年 已经是 512MB 内存的极限价，$49.99/年 是 1GB 内存的正价。看到 0 元、1 元、9.9 元包年，不用想，一定是共享账号或纯骗。
  6. 看支付方式：官方支持支付宝、PayPal、信用卡。只收 USDT、礼品卡、私人转账的，没有交易保障。

把这 6 条当成肌肉记忆，你会发现市面上绝大多数「bug 价」在第二条就露馅了。

九、风险提示

  • 账号安全：开启两步验证，使用独立邮箱，不要与他人共享账号；
  • 支付安全：优先官方支付宝/PayPal/信用卡通道，任何要求你提供账号密码的「代付」都要拒绝；
  • 服务条款：搬瓦工禁止滥用、扫描、代理黑产等行为，违规会导致停机且不退款；
  • 退款政策：官方提供 30 天退款保证，但有条件限制，购买前请阅读 TOS；
  • 库存与价格：本文所有价格均为核对时的公开信息，最终以官方下单页为准。
