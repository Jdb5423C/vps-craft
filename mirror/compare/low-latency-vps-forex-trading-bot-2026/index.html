量化/EA 交易要低延迟：跑外汇机器人该选哪台 VPS？就近机房实测（2026）

EA/量化机器人不能跑家里电脑。延迟只看 VPS 到券商机房的距离，本文用 NY4/LD4/TY3 机房地图，教你在 DMIT、RackNerd、Vultr、HostDare 里按券商就近选节点。

⚠️ 重要声明与免责提示：
本文内容及各机房延迟数据均来源于网络（由玩家及社区公开分享，参考来源包括 NodeSeek 社区实测 与 LowEndTalk 讨论）。鉴于跨境路由与各机房突发网络策略随时变动，本文信息可能已经过时，请以各商家的实时线路和性能为准。

EA/量化机器人为什么不能跑在家里电脑

很多新手以为，EA（Expert Advisor，专家顾问）或量化交易机器人只要挂在电脑上、开着 MT4/MT5 就行。现实更硬：家里电脑半夜自动更新重启、断电、宽带掉线、公网 IP 变动，任何一件都会让 EA 停跑，而你正在睡觉。漏掉一段行情事小，碰上非农、CPI、利率决议这类关键数据发布时停单，可能直接吃滑点，甚至错过大行情。

把机器人托管到 VPS（Virtual Private Server，虚拟专用服务器）上，等于给它一台 7×24 小时不掉电、不断网的独立机器，你本地电脑关了它照常跑。这也是自动交易老手几乎都用 VPS 的原因。但本文讲的不是「随便买台 VPS」，而是「按券商机房就近选，把下单链路压到最短」。本文只讨论合规的自动交易托管，不构成任何投资建议。

延迟到底是什么：为什么 VPS 到券商的距离才关键

延迟（latency）通常指往返时间 RTT（round-trip time）：你的 EA 把下单指令从 VPS 发到券商的撮合引擎（matching engine），再收到确认，整个来回所花的时间，单位是毫秒（ms）。光在光纤里的速度约为真空光速的三分之二，也就是每毫秒约 200 公里；换算成往返，路径每增加约 200 公里，RTT 大约多 2 毫秒。这是物理下限，换 CPU、加内存、装加速软件都绕不过去。

关键认知：延迟只取决于「VPS 与券商交易服务器」之间的距离和路径质量，和你本人在哪里无关。你从中国大陆用远程桌面（RDP）连 VPS，卡的只是你看图表、点按钮的体验，不影响 EA 在 VPS 内部的执行，也不影响 VPS 到券商的成交速度。所以选机房要看券商在哪，而不是看你自己在哪个城市。这一点后面还会反复出现，因为它是最常被搞错的变量。

还要区分两种「延迟」：一种是网络 RTT，用 ping 就能测；另一种是订单端到端延迟，包含 VPS 本机处理、虚拟化开销、公网路由、券商接入、撮合与回报。ping 低只说明网络这一段短，不代表成交一定快。评估时两者都要看，不能只盯一个数字。

券商机房地图：NY4 / LD4 / TY3 分别服务谁

主流零售外汇与差价合约券商，常把交易服务器放在 Equinix 等中立机房的金融生态里。最常被提到的是三个站点：纽约 NY4、伦敦 LD4、东京 TY3。它们的地址和规格可以在 Equinix 官网查到：NY4 位于美国新泽西州 Secaucus（755 Secaucus Rd），LD4 位于英国伦敦 Slough 的 Slough Trading Estate，TY3 位于日本东京江东区（1-9-20 Edagawa）。

怎么确认自己的券商在哪？第一步看 MT4/MT5 登录时的服务器名和底部状态栏，很多会带 NY4、LD4、TY3、LD5 之类的字样；第二步用 tracert 或 pathping 追到最后一跳，看机房或网络商的命名；第三步直接问券商客服「我的实盘账户交易服务器托管在哪个机房」。三步交叉，比任何第三方清单都可靠。

除这三个，法兰克福 FR2/FR5 服务欧陆（DAX、EUR/CHF 等），新加坡与香港也有区域接入点。但楼宇代码、券商在哪个楼、哪个账号连哪个服务器，都可能随业务调整，务必以经纪商与机房官方的最新说明为准。不要凭「城市名」猜机房，更不要凭「离中国近」猜延迟。

延迟档位与代价：不同策略要不同延迟

延迟目标没有统一标准，取决于策略。下面是一个经验分档，数字是量级，不是承诺：

  • 手动交易、日线/波段 EA：50–100ms 往往已经够用，普通同洲 VPS 就能满足。
  • 常规趋势、网格、多品种 EA：10–30ms 通常足够，重点是稳定不断线。
  • 剥头皮、新闻交易、套利：5ms 以内才有意义，同楼 cross-connect 可做到 1ms 以内。
  • 超过 50ms：先怀疑地理错配；超过 150ms：基本可以判定选错大洲。

作为参照，MetaQuotes 官方介绍 MetaTrader VPS 时称，其服务对约 70% 的券商交易服务器可做到 3ms 以内，约五分之一可做到 1ms 以内；这说的是它自己的托管点，不是通用 VPS 的普遍水平。IC Markets 也公开表示，其 MT4/MT5 服务器位于 Equinix NY4，NY4 同楼或专线接入的主要 VPS 供应商可做到 1ms 以内。把这些数字当参照，而不是当购买承诺。

延迟高的直接代价有三类：滑点（slippage），订单在路上时价格已动，成交价变差；重新报价（requote），部分执行模式下价格跳动会驳回原单，重试又多一个往返；错过入场，突破、新闻、套利类策略依赖毫秒级触发。除此之外，点差、流动性、执行模式、券商风控也会影响成交，不能把所有问题都归给 VPS。

网络抖动与丢包：平均延迟好看不代表稳定

选机房不能只看平均 ping。网络抖动（jitter）和丢包（packet loss）对 EA 的伤害往往更大：平均 30ms 但抖动正负 20ms，可能比稳定 45ms 更难用；丢包 1%–2% 就会触发 TCP 重传，MT4/MT5 可能掉线重连，EA 在重连期间收不到 tick，挂单和止损都可能延迟执行。

抖动常见来源：跨洲链路拥塞、机房上行被打满、家用宽带共享、虚拟化宿主超卖、路由绕行。伦敦、纽约开盘前后和重大数据发布时，公网路径的排队延迟会明显上升；同一栋楼内的 cross-connect 则基本不受公网拥塞影响，这也是专业外汇 VPS 的价值所在。

测量时不要只 ping 十次。至少跑 100–500 个包，看平均、最大、丢包率和标准差；再用 pathping（Windows）或 MTR（Linux/路由器）看每一跳的延迟与丢包，判断问题出在本地、国际出口还是机房侧。分时段测：亚洲午后、伦敦开盘、纽约开盘、非农发布各测一轮，才有参考价值。

另一个容易忽略的点：MT4/MT5 终端右下角显示的 ping，有时测的是到接入点（access point）的往返，不一定等于到最终撮合引擎的路径。想验证真实成交延迟，可以对比订单日志里的下单时间与成交时间，连续统计几十笔，比单看 ping 更可靠。

系统上，MT4/MT5 原生是 Windows 程序，绝大多数 EA、指标和插件也是 Windows-only；Linux 版 MT5 与 Wine 方案能跑一部分，但兼容性和排障成本更高。所以做 EA 托管，Windows VPS 基本是刚需，Windows 授权通常需要自理或包含在套餐里，下单前看清。

在线率要算账：99.9% 约等于每年 8.7 小时不可用，99.99% 约等于每月不到 5 分钟。7×24 跑 EA，除了看 SLA，还要看商家是否有冗余网络、自动重启、快照/备份、独立 IP 和 DDoS 防护。CPU 不只看核数，单核性能和是否超售更影响 MT5 的 tick 处理；内存 2GB 起步，Windows 本身还要占一部分。

自己动手测延迟

选好节点后，务必从 VPS 实测到券商服务器的延迟，而不是只看商家宣传。把下面命令里的主机名/IP 换成你券商的 server：

BASH 
# 券商服务器主机名可在 MT4/MT5 登录框或状态栏看到，例如 broker-server.example.com
# 追路由，看最后一跳是否落在目标机房
tracert broker-server.example.com

# 从 VPS 连续测往返延迟，至少 100 个包，重点看丢包与最大延迟
ping broker-server-ip -n 100

# Windows 下进一步看每一跳的丢包与延迟
pathping broker-server-ip

建议按四步做：第一，确认服务器主机名和 IP；第二，连续 ping 100–500 个包，记录平均、最大、丢包率；第三，用 pathping 或 MTR 定位问题跳；第四，在伦敦开盘、纽约开盘、重大数据发布前后各测一轮，观察抖动。只 ping 一次、只看最小值，很容易被偶然的好线路骗到。

MT4/MT5 状态栏右下角也会显示连接延迟，适合快速判断；但它可能只是到接入点的 ping，不能完全代表成交路径。更严谨的做法是对比订单日志中的下单与成交时间戳，连续统计几十笔，得到端到端的实际延迟分布。若同城长期高于 10ms、跨洲长期高于 100ms，优先换节点，而不是加配置。

成本与合规：月费之外还有哪些账

交易 VPS 的成本不只是一行月费。常见构成包括：Windows 授权、独立 IPv4、带宽与流量、备份/快照、DDoS 防护、控制面板，以及可选的管理服务。低价套餐往往在 CPU 超售、带宽共享、备份缺失上做减法；对 7×24 跑 EA 的场景，稳定性和可恢复性比省几美元更重要。

还有几笔隐性成本：为「低延迟」买了高配，却选错机房，钱花在无用的 CPU 上；只买一台 VPS，没有备用节点，宕机时无法切换；用第三方 EA 却没有正版授权，或把账号密码交给不可信的「代挂」，带来账号与资金风险。先把这些算清楚，再比较月费。

合规方面，VPS 本身只是基础设施，不等于可以绕过任何规则。使用前应确认：券商的客户协议是否允许 EA/算法交易，是否禁止延迟套利、滥用报价、过度剥头皮等行为；你所在司法辖区对外汇保证金交易、自动交易和跨境网络服务的规定；开户 KYC、资金来源与税务申报要求；第三方 EA 的授权范围。VPS 不是监管套利的工具，违规策略换到更快的机器上只会放大风险。

安全上，至少做到：强密码并尽量限制 RDP 来源 IP、开启多因素认证（若商家支持）、及时打补丁、关闭不必要的端口、定期快照、不要把交易账号密码明文放在桌面。VPS 被入侵的代价不只是掉线，还可能是账号被接管。

大陆用户特别提示：支付、退款与 RDP 误区

对国内用户，有三点要单独说。第一是支付：DMIT、HostDare 通常支持支付宝，下单门槛较低；Vultr、RackNerd 多收双币信用卡或 PayPal，没有双币卡的用户优先前两家。支付方式会调整，具体以结算页显示为准。

第二是退款：不同商家、不同套餐的退款规则差异很大，有的只退账户余额，有的限新购数日内，有的特价套餐不退。不要按「别人说能退」下单，先读商家条款，首次尽量月付，验证延迟和稳定性后再考虑长期。

第三是最常被误解的：你在中国用 RDP 连 VPS 感觉卡，只是你看图表、点按钮卡，EA 的成交速度看的是 VPS 到券商的距离，跟你在哪没关系。所以别迷信「选离中国近的机房」。券商在 NY4，却因为「东京离中国近」买了日本节点，延迟反而更高。把「RDP 体验」和「成交延迟」分开想，决策就清楚了。RDP 线路值得优化，但那是为了你手动干预时好用，不是为了 EA 成交。

另外记得把 Windows 时区、NTP 时间同步和 MT4/MT5 的服务器时间对齐。EA 里常有时段过滤、新闻过滤，时间漂移会导致策略在错误的时间开平仓，这类问题比多几毫秒更常见。

常见误区速查

  • 家宽也能跑 EA？不能当生产环境。家宽没有静态 IP、没有 SLA，断电、重启、运营商维护都会停单。
  • 便宜 VPS 也能低延迟？价格不决定延迟，位置才决定。但过度超售的便宜机器会增加本机处理和抖动。
  • 带宽越大延迟越低？不是。带宽影响吞吐，延迟看距离、路由和排队；100Mbps 的家宽打不过 10Mbps 的同城专线。
  • 离中国近就快？对 EA 成交没意义。你要近的是券商交易服务器，不是上海或香港。
  • ping 低就一定成交快？不一定。ping 可能只到接入点，成交还受券商撮合、风控和流动性影响。
  • 加 CPU/内存能救高延迟？不能。选址错误是物理距离问题，配置只能减少本机处理时间。

风险提示：通用商家不是同楼，滑点也未必怪 VPS

再说一遍冷水：白名单四家是通用 VPS，不是 Equinix 同楼 colocation，不能承诺 1ms 以内。若你做高频剥头皮或新闻交易，且券商在 NY4/LD4，专业外汇 VPS（如 Beeks 这类以金融市场为主的供应商）通过同楼 cross-connect 才可能做到 1ms 以内；它们不在本站白名单，只作参照。不要指望通用商家解决同楼级别的需求。

滑点也不一定是 VPS 的锅。券商流动性、点差、执行模式、风控、新闻时段的流动性抽离，都会造成滑点；先测 RTT、再看订单日志，再判断责任。宕机同样要认真对待：7×24 不能停，选高在线率、能自动重启、有备份的商家，永远不要把家用电脑或家宽当生产环境。本文只讨论合规托管，不构成投资建议。

选购清单：按预算与券商一句话推荐

  • 券商在 NY4、想要多区域和 Windows 覆盖、预算灵活：Vultr 纽约/新泽西，高频实例更稳。
  • 券商在 NY4、只做美盘、想压成本：RackNerd 纽约/新泽西，但先确认配置跑得动你的 EA。
  • 券商在 TY3（亚盘 JPY）、想用支付宝：DMIT 东京或 HostDare 日本 SoftBank。
  • 券商在 LD4/LD5（欧盘）、想就近：Vultr 伦敦（若有）或法兰克福。
  • 券商在新加坡/香港：Vultr 新加坡或 DMIT 香港。
  • 大陆用户没有双币卡、优先支付宝：DMIT 或 HostDare 的就近节点。

记住三条：EA 数量决定内存，Windows 决定系统盘，券商机房决定节点。这三条定下来，配置和区域都不会太离谱。首次尽量月付，用低配验证延迟和稳定性，再决定是否长期。

结语

跑 EA/量化机器人，VPS 是必需品，但「选对机房」比「买贵机器」重要得多。先确认券商在哪个 Equinix 机房，再选同城或同洲节点，最后从 VPS 实测 RTT、抖动和丢包。白名单四家里，Vultr 区域最广，RackNerd 便宜但偏美国，DMIT 与 HostDare 对大陆用户的支付更友好。所有延迟、价格、库存和网络条件都会变，请以商家页面和你的实测为准。

常见热点问题解答 (FAQ)

EA/量化机器人为什么不能跑在家里电脑？

家里电脑会半夜自动更新重启、断电、宽带掉线、公网 IP 变动，任意一件都会让 EA 停跑。托管到 VPS 等于给它一台 7×24 不掉电不断网的机器；停单可能直接吃滑点。

延迟到底由什么决定？

主要由 VPS 到券商交易服务器的物理距离和路径质量决定，和你本人在哪无关。RDP 卡只是看图表卡，不影响 EA 成交。选节点要按券商机房选，不是按离中国近选。

券商在 NY4、LD4、TY3 分别该选哪个节点？

NY4 选纽约/新泽西的 Vultr 或 RackNerd；LD4/LD5 选伦敦或法兰克福的 Vultr；TY3 选 DMIT 东京、HostDare 日本或 Vultr 东京；新加坡/香港券商选 Vultr 新加坡或 DMIT 香港。具体机房与账号服务器以经纪商官方为准。

白名单四家能拿到小于 1ms 吗？

不能承诺。它们是通用 VPS，不是 Equinix 同楼 colocation；同城不同楼通常是 1–5ms 量级。小于 1ms 需要专业外汇 VPS 的同楼 cross-connect。

平均 ping 很低，为什么 EA 还是掉线？

可能是抖动或丢包。看平均值不够，要连续测 100–500 个包，记录最大延迟、丢包率和标准差，并用 pathping/MTR 定位问题跳。

MT5 右下角的 ping 能代表成交延迟吗？

不一定。它可能测的是到接入点的往返，不等于到最终撮合引擎。更可靠的方法是对比订单日志中的下单与成交时间戳。

大陆用户下单要注意什么？

支付和退款规则以商家结算页为准；没有双币卡可优先看支持支付宝的商家；首次月付试水，先验证延迟、丢包和稳定性，再考虑长期。
