一、对象存储的“数据重力”陷阱：为什么出网流量才是账单刺客？

在为 VPS 部署异地容灾、数据库快照或自建图床时，绝大多数站长首先关注的往往是“每 GB 存储多少钱”。然而，在云存储领域，这恰恰是亚马逊 AWS S3 等传统巨头设立的经典“数据重力（Data Gravity）”收费陷阱：

  • 进门便宜，出门天价：向对象存储上传数据（Ingress）全线免费，存储单价看似只需 $0.023/GB·月。然而，当你的 VPS 突发磁盘损坏或遭遇机房拔线，需要从云端下载几百 GB 乃至数 TB 数据进行紧急恢复时，AWS S3 会向你收取高达 $0.09 美元/GB 的公网出流量费（Egress Bandwidth）。一次 5TB 的数据库灾难恢复，仅取回流量费用就高达 $450 美元，是该数据全年静态存储费用的数倍！
  • 三大新锐破局者：为了打破 AWS 的出流量暴利垄断，Cloudflare R2、Backblaze B2 与 Wasabi 分别凭借自身的基础设施优势，重构了对象存储的计价游戏规则。但在选择具体平台前，必须算清“存储费、出网费、API 操作费与隐藏限制”这四本账。

三、三大典型应用场景真实成本精算模型

场景 A：个人博客与小型 VPS 灾难恢复（Cold Disaster Recovery）

参数设定：VPS 网站文件与数据库压缩包总体积 200 GB；每天凌晨做一次增量同步；平时几乎不发生公网下载；假设某月服务器物理机宕机，触发一次 200 GB 全量拉回：

  • Backblaze B2 账单：
    • 存储费：(200GB - 10GB 免费) × $0.006 = $1.14
    • 出网费：当月下载 200GB，远低于当月存储量的 3 倍免费限额（600GB），出网费 = $0.00
    • API 请求费：每日同步约产生几万次请求，约 $0.02
    • 当月总开销：约 $1.16 美元（最具杀伤力的极致性价比！）
  • Cloudflare R2 账单：
    • 存储费：(200GB - 10GB 免费) × $0.015 = $2.85
    • 出网费：全量免收 = $0.00
    • API 请求费：在免费额度内 = $0.00
    • 当月总开销：约 $2.85 美元
  • Wasabi 账单：
    • 存储费：触发 1TB 最低托底门槛 = $7.99 美元
    • 出网费：未超过 1x 存储量，免费
    • 当月总开销：$7.99 美元（小容量场景严重亏损）

场景 B：自建高频图床与媒体静态分发（Media Assets Hosting）

参数设定：存储静态图片与音视频共 500 GB；对外提供 Web 访问与 CDN 回源，每月产生 2,500 GB (2.5TB) 公网出流量（出流量是存储体积的 5 倍）：

  • Wasabi：直接判负。其 Fair Use 政策明确禁止“出流量大于存储量”的业务场景。5 倍的出流量会直接触发其反滥用邮件警告，甚至被强制转入高单价计费或关停 Bucket。
  • Cloudflare R2 原生托管：
    • 存储费：500GB × $0.015 = $7.50
    • 出网费：2.5TB 全免 = $0.00
    • 操作费：假设产生 300 万次图片读取（Class B），超出免费部分收约 $0.72
    • 总费用：约 $8.22 美元/月（架构极其简单，零 CDN 配置即可全球秒开）
  • Backblaze B2 + Cloudflare CDN 联盟模式（黄金搭档）：
    • 利用 Cloudflare 与 Backblaze 的 Bandwidth Alliance（带宽联盟） 官方协议，所有从 Cloudflare 边缘回源到 Backblaze B2 的出流量完全免费（100% Free Egress）！
    • 存储费：500GB × $0.006 = $3.00
    • 出网费：通过 Cloudflare 免费 CNAME 接入，$0.00
    • 总费用：仅 $3.00 美元/月（大流量静态网站的最优解！）

场景 C：企业级私有网盘与海量冷沉淀（Enterprise Deep Archive）

参数设定：公司自建 Nextcloud 或 MinIO 集群，存储长期不变动的研发日志与备份共 10 TB；每月偶尔下载 2 TB 归档文件进行抽检：

  • Wasabi：10TB 存储 = $79.90/月；无任何 API 读写费；下载 2TB 远低于 10TB（符合 Fair Use）。适合预算固定、无技术运维精力调优 API 的传统企业。
  • Backblaze B2：10TB 存储 = $60.00/月；免费出网额度高达 30TB/月；2TB 抽检取回完全免费。总账单仅需 $60.00/月。
  • Cloudflare R2：10TB 存储 = $150.00/月。在大容量纯静态沉淀场景下，单价劣势明显放大。

四、避坑指南：新手最容易踩的三大“隐形成本暗礁”

  1. Cloudflare R2 的“海量小文件 Class A 刺客”： R2 免的是出网带宽，但 Class A（写入与列举）请求费高达 $4.50/百万次。如果你使用未经参数调优的 Restic 或 Duplicati 备份数百万个小文件（如 Node.js 的 node_modules 或小图片），每次备份都会产生巨量 PutObject 与 ListObjects 请求。曾有用户在 R2 存了 50GB 数据只花了 $0.75，但因配置不当产生了 1500 万次写请求，月底账单被反向收缴了近 $70 美元的操作费！
  2. Wasabi 的“90 天幽灵计费”： 许多开发者把 Wasabi 当作日常临时中转站，今天上传 500GB 临时镜像，明天删除。然而，Wasabi 的计费引擎会为该对象建立一个 90 天的虚拟计时器，在接下来的 89 天内，系统每天都会继续对这 500GB 虚拟空间扣费（计费名称为 Timed Storage）。短期频繁轮转的快照方案千万不能选 Wasabi。
  3. Backblaze B2 必须配置生命周期规则（Lifecycle Rules）： B2 默认的桶设置是“保留所有历史版本（Keep all versions）”。如果你每天用同名文件覆盖备份，旧文件不会被物理删除，而是作为隐藏版本累积堆叠，导致存储容量像滚雪球一样暴涨。创建桶后第一件事，是将生命周期调整为 "Keep only the last version of the file" 或自定义 30 天后自动清理。

五、生产级灾备对接实战：Rclone 与 Restic 配置最佳实践

1. Rclone 高效同步至 Cloudflare R2（S3 协议标准化）

在 VPS 上运行 rclone config，选择 S3 Compatible，关键字段填写如下：

SHELL / COMMAND 
[r2-backup]
type = s3
provider = Cloudflare
access_key_id = 4cxxxxxxxxxxxxxxxxxxxxxxxxxxxx
secret_access_key = 9fxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
endpoint = https://<ACCOUNT_ID>.r2.cloudflarestorage.com
acl = private

避坑同步命令（启用多线程分块并限制小文件列举）：

SHELL / COMMAND 
# 加上 --fast-list 可以大幅减少 ListObjects (Class A) 操作次数，节省 API 费用
rclone sync /var/www r2-backup:my-vps-bucket/www_backup \
  --fast-list \
  --transfers 4 \
  --checkers 8 \
  --s3-upload-concurrency 4

2. Restic 增量加密去重对接 Backblaze B2

Restic 支持块级去重与端到端加密，与 B2 结合是极其优雅的灾备方案：

SHELL / COMMAND 
# 配置环境变量
export B2_ACCOUNT_ID="00xxxxxxxxxxxx"
export B2_ACCOUNT_KEY="K00xxxxxxxxxxxxxxxxxxxxxxx"
export RESTIC_REPOSITORY="b2:my-backup-vault:restic-repo"
export RESTIC_PASSWORD="YourStrongEncryptionPassword"

# 初始化仓库
restic init

# 执行增量备份并排除临时目录
restic backup /var/www /etc /var/vmail \
  --exclude="/var/www/*/cache" \
  --exclude="node_modules"

# 定期清理 30 天以前的旧快照并释放磁盘
restic forget --keep-daily 7 --keep-weekly 4 --keep-monthly 12 --prune

六、选型最终结论：一张决策树为你指路

  • 首选 Backblaze B2：如果你是个人开发者、中小站长，备份容量在 1TB 以内，平时极少取回数据，或者希望通过 Cloudflare 免费分发静态资源。B2 的 $0.006 单价、10GB 免绑卡额度与成熟度是目前全网综合成本最低的王者。
  • 首选 Cloudflare R2：如果你的业务具有“高频出网”特征（例如自建 API 媒体转码、公共镜像分发、动态下载站点），或者全套技术栈已深深扎根于 Cloudflare Workers / Pages。它的零出网费能彻底锁死带宽峰值风险。
  • 谨慎评估 Wasabi：仅当你的数据规模长期稳定在 2TB 以上，文件生命周期严格大于 90 天，且极度厌恶计算 API 操作费时，Wasabi 的一口价全包模式才具备吸引力。

常见热点问题解答 (FAQ)

Backblaze B2 和 Cloudflare R2 都是 S3 兼容的吗？

是的。两者均完整支持 AWS S3 Signature Version 4 (v4) 签名协议。包括 AWS CLI、rclone、restic、Duplicati、MinIO Client、Cyberduck 在内的所有现代客户端，均可无缝直接连接。

为什么说 B2 + Cloudflare CDN 是零出网费？

Backblaze 和 Cloudflare 是“带宽联盟（Bandwidth Alliance）”的发起成员。当客户端通过解析到 Cloudflare 的自定义域名访问 Backblaze B2 的桶资源时，双方在光纤专线互联处免除了全部流量过路费，因此 Backblaze 对来自 Cloudflare IP 的回源流量实行 0 计费。

R2 的 Class A 和 Class B 操作有什么区别？

Class A 包括 PutObject、CopyObject、ListObjects、CreateMultipartUpload 等写入与查询目录操作，单价较贵（$4.50/百万次）；Class B 包括 GetObject、HeadObject 等读取文件与元数据操作，单价极低（$0.36/百万次）。

Wasabi 的 90 天保留期具体是怎么算的？

如果你上传了一个 10GB 的文件并在第 2 天将其删除，Wasabi 会继续对这 10GB 空间收取剩余 88 天的存储费用。只有当文件存在满 90 天后再删除，才不会产生任何追加扣费。
