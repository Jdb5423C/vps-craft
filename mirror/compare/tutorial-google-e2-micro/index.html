手把手申请 Google Cloud 永久免费 e2-micro 机器（2026 白话版）

2026-07-18动态实时复核有效846 字3 分钟阅读

谷歌云那台 1G 内存、永久免费的 e2-micro 机器，适合挂轻量服务、当备份节点。这篇大白话教你注册、开预算警报（防天价账单）、建机器、连上去，并避开 SSD / 静态 IP 这些隐形扣费陷阱。

📂本文收录于 《2026 全球永久免费云服务器与免费 VPS 实测大全》 专栏，点击查看全景对比表与更多免信用卡白嫖攻略。

你搜「Google 永久免费机器」「e2-micro 怎么申请」——谷歌云确实有一台永久免费的小机器：e2-micro（0.25 核 / 1G 内存）。配置不高，但挂个轻量服务、当第二台备份节点、练手完全够。这篇大白话带你从注册到开机，并提前把「天价账单」的雷排掉。

一、你能永久免费拿到啥

  • 1 台 e2-micro 实例/月：0.25 vCPU + 1GB 内存，仅限 us-central1（爱荷华）/ us-west1（俄勒冈）/ us-east1（南卡） 三个区域，非抢占式。
  • 30GB 标准 HDD 系统盘（注意：必须是标准盘，SSD 要钱）。
  • 每月 1GB 出站流量（超出按 $0.12/GB 计）。
  • 外加 5GB Cloud Storage、1TB BigQuery 查询等月额度，以及 $300 的 90 天试用金（和免费档是两码事）。

二、注册前要准备

  • 一个 Google 账号（普通 Gmail 即可）。
  • 国际信用卡（Visa / MasterCard / 运通），部分地区支持 PayPal / 借记卡。国内建议全币种信用卡，虚拟卡可能被拒。
  • 能收验证码的手机号（国内手机号也行）。
  • 稳定的国际网络环境。

三、第 1 步：注册 + 顺手设「预算警报」（最最重要）

打开 cloud.google.com/free → 用 Google 账号登录 → 「Get started for free」→ 填卡（谷歌会做 $0~$1 临时授权，几天后退还，试用期结束后只要不超量也不扣）。

⚠️ 注册完第一件事：设一个 $1 预算警报，这比什么都重要：

  • 左上角菜单 → Billing → Budgets & Alerts → Create Budget。
  • 金额填 $1，把所有通知阈值（50% / 90% / 100%）都打开。
  • 这样任何一笔扣费（哪怕是动到试用金）都会立刻邮件提醒你，等于你的预警系统。

四、第 2 步：开 Compute Engine API + 建机器

  • 菜单 → APIs & Services → Library → 搜 Compute Engine API → Enable（不开就没法建 VM）。
  • 菜单 → Compute Engine → VM Instances → Create Instance。
  • 区域：选上面三个免费区域之一（如 us-central1），可用区随意。
  • 机型：General purpose → E2 → e2-micro（0.25 vCPU / 1GB），认准「1 free e2-micro instance per month」字样。
  • 启动盘：Change → Ubuntu 22.04/24.04 LTS → 大小 30GB → Standard persistent disk（标准盘，别选 SSD）。
  • 防火墙：不要勾 Allow HTTP/HTTPS（我们用密钥或别的方式访问，避免暴露）。
  • 网络：不要申请静态 IP（空闲静态 IP 约 $7.20/月，白嫖党的大坑）。
  • 点 Create，约 1 分钟开机，记下外部 IP。

五、第 3 步：连上去

控制台列表里点机器右侧的 SSH 按钮即可浏览器内登录；或在本地 ssh 你的用户名@外部IP（Ubuntu 镜像默认用户是 ubuntu）。

六、最容易踩的隐形扣费坑

  • 静态 IP 空闲费：机器删了但 IP 留着 = 每月 $7.20 打水漂。不用就一起删。
  • SSD 系统盘：免费档只覆盖标准 HDD，30GB SSD 约 $5.10/月。
  • 出站流量超 1GB：公网流量 $0.12/GB，图片站月吐 10GB 就多 $1.08。
  • Load Balancer / GPU / Windows：统统不在免费范围，碰都别碰。
  • 区域限制：免费 e2-micro 只在那三个美区，选错区域会整月计费。

想更稳？把 Oracle 免费 ARM 当主力、这台 e2-micro 当第二节点，再配一台 年付便宜 VPS（如 DediRock $6.45/年）兜底，三云互备基本不花钱。

常见热点问题解答 (FAQ)

e2-micro 永久免费是真的吗？

真的，只要不超量（1 台 / 30G 标准盘 / 1G 出站）就一直免费，和 $300 试用金无关。

一定要绑卡吗？

用 GCP 服务要绑卡做验证（临时 $0~$1 预授权，会退）；但纯玩 Gemini API 走 AI Studio 不用卡。

怎样才不会收到天价账单？

注册后立刻设 $1 预算警报，并且永远别选 SSD、别留空闲静态 IP。

选错区域会怎样？

非免区 e2-micro 会整月按量计费，建机前先确认是三个美区之一。
