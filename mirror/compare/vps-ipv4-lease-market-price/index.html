最近几年买海外 VPS 的朋友，应该都明显感觉到一件事：IPv4 地址越来越贵，而且贵得理直气壮。几年前一个独立 IP 常常白送，现在不少商家明码标价收你每个 2 到 3 美元/月，买断更是动辄几十美元一个。这背后不是商家单纯想割韭菜，而是一整套全球资源枯竭加上二级市场炒作的连锁反应。本文把 2026 年 IPv4 租用、转让、买断的真实行情摊开给你看，顺便算清楚对个人和小团队来说，到底哪种方案最划算。

IPv4 是怎么一步步被用光的

IPv4 用的是 32 位地址，理论上最多约 43 亿个地址。听起来很多，但全球联网设备早在十多年前就超过了这个数字。地址分配由五个区域互联网注册机构（RIR）负责，它们手里的免费池一个接一个见底，枯竭时间线清清楚楚：

  • 2011 年 4 月：APNIC（亚太）最先耗尽免费池，成为第一个"弹尽粮绝"的注册局。
  • 2012 年 9 月：RIPE NCC（欧洲、中东、中亚）进入最后一段 /8，开始限量配给。
  • 2014 年 6 月：LACNIC（拉美）耗尽，转入等待名单。
  • 2015 年 9 月：ARIN（北美）彻底无新地址可分配。
  • 2020 年 1 月：AFRINIC（非洲）成为最后一个耗尽免费池的注册局。

从那以后，任何组织想要新 IPv4，只能在二级市场向持有者购买或租用，没有第三种合法来源。稀缺是结构性的，不是周期性的——这才是价格只涨不跌的根本原因。

可以看到几个关键点。第一，单个 IP 的买价集中在 15–35 美元区间，小段（/24）因为流动性最好反而单价偏高。第二，租用价普遍落在 0.30–0.55 美元/IP/月，算下来一年也就 3.6–6.6 美元，比买断便宜一个数量级还多。第三，越是大的块，单价越低——一个 /16 整机段每 IP 能压到 9–22 美元，但总价要上百万美元，显然不是普通人玩得动的。

区域也有价差。RIPE NCC（欧洲）因为流转手续干净、需求旺，单价常常站在 30 美元上下；ARIN（北美）受美国云厂商和 AI 基建拉动，2026 年还涨了约 5%；APNIC（亚太）供给最紧，部分挂牌价能到 35 美元以上；AFRINIC 和 LACNIC 相对便宜但可选存量少。买之前一定记得核查黑名单历史和 BGP 路由记录，带过 spam、滥用记录的段会被打折扣甚至卖不出去。

为什么 VPS 商家还要收你 2–3 美元/IP 的额外费

你可能会问：市场租价才 0.30–0.55 美元，凭什么商家收我 2–3 美元？这中间的差价并不是纯利润，主要由几块构成。

  • 获取成本加价：商家不是按需租一个就给你一个，它要先向市场批量拿段、做 LOA（授权书）、接入自己的网络并做反欺诈清洗，这些都有固定开销，平摊到每个 IP 上就高于裸租价。
  • 运维与风控：每个独立 IP 都要做反向解析（PTR）、黑名单监控、滥用投诉处理。一旦出问题影响整段声誉，商家要花人力去擦屁股。
  • 资源占位的机会成本：一个干净 IP 给到你，商家就少了一个可以卖给高价客户（邮件服务、代理、VPN）的名额，附加费里含了这部分机会成本。
  • 合规与转移费：部分区域（如 ARIN）的"租用"实质是 reassignment 记录，跨注册局转移还要交 500–5000 美元不等的手续费，最终都会摊进售价。

所以看到 RackNerd、ColoCrossing 这类年付十来美元的套餐"送一个 IP"，那个 IP 的成本是被套餐整体薄利分摊掉的；而 Vultr 这类按量计费、可以弹性加 IP 的商家，就直接把附加费单列出来，目前每个额外 IPv4 大约 2–3 美元/月。这不代表谁更黑，而是商业模式不同。

租还是买？给个人和小团队算一笔账

对个人站长、小团队来说，99% 的情况都该选租（也就是跟着 VPS 套餐走），而不是自己到二级市场买断。我们算个直观的账：

  1. 假设你长期需要 5 个独立 IP，自己买断按 30 美元/IP 算，一次性要掏 150 美元，这还不算转移费、年费、清洗成本。
  2. 同样 5 个 IP 跟商家租，按 2.5 美元/IP/月 算，一个月 12.5 美元，一年 150 美元——等于把买断的钱摊成了十年才花完。
  3. 更关键的是，你自己的段要自己维护声誉、自己处理滥用工单，对个人而言时间成本远高于那点差价。

买断只在一种场景划算：你是大客户，需要成百上千个 IP、且要长期持有甚至等待升值，那种情况下批量 /20 以上每 IP 单价能压到 20 美元出头，持有成本被摊薄，未来还有资产保值的想象空间。普通用户完全不用考虑。

NAT VPS 与 IPv6：真正能省钱的两条路

如果你只是想省钱，又不是非得要独立公网 IP，有两条更聪明的路。

第一条路：NAT VPS

NAT VPS 是多个用户共享同一个公网 IPv4，靠端口映射把流量分发给你的内网地址。入站访问通过不同端口区分，比如你的 SSH 可能被分配到 22022 端口。它便宜得离谱，很多商家 NAT 套餐年付只要几美元。适合跑爬虫、内网隧道、私有服务这类不需要对外固定 IP 的场景。缺点是不能直接对外提供 80/443 标准 Web 服务（除非用反代或 CDN 兜一层），而且端口容易冲突。

第二条路：IPv6 Only 或双栈

IPv6 地址空间近乎无限，/64 前缀就有 2 的 64 次方个地址，服务商基本都是免费送。Vultr、Hetzner、RackNerd 这些主流厂商默认都给双栈（1 个 IPv4 + 一个 /64 IPv6）。如果你的业务面向的是现代网络（移动端、海外用户），纯 IPv6 或双栈能直接省掉 IPv4 附加费。国内访问 IPv6 的稳定性这几年在变好，但仍有盲区，所以面向大陆用户的正式站点建议至少双栈保底。

想确认自己的 VPS 有没有拿到 IPv6，可以跑下面这条命令：

BASH 
ip -6 addr show
ping6 ipv6.google.com
curl -6 https://ifconfig.co

如果前两条有回显、第三条能返回你的 IPv6 地址，说明双栈已经通了。需要纯 IPv4 资源时，再在前面挡一个 NAT64/DNS64 网关或用 3proxy 做双栈出口即可。

实战：怎么查、怎么选、怎么避坑

落到具体操作，给你一套可照搬的流程。

  • 查行情：下单前先去 IPv4.Global 的 leasing 页面、IPv4Center 的 price tracker 看当下成交区间，心里有数才不会被人按高价收。
  • 比套餐：ColoCrossing 年付 10.99 美元起的套餐默认带 1 个 IPv4；RackNerd 年付 10 美元出头的神车也含 IP。先选"含 IP 的套餐"，比事后单加便宜得多。
  • 避坑一：首年低价、续费翻倍的套路在 IP 附加费上同样存在，下单前把续费价和额外 IP 价一起看。
  • 避坑二：别在来路不明的平台买段，一定要走有 escrow（第三方托管）的正规经纪，否则可能买到被污染、随时被回收的地址。
  • 避坑三：AWS、Google Cloud、Azure 如今对所有公网 IPv4 单独计费（约 0.005 美元/小时，折合每月近 3.6 美元），上云前把这块成本算进 TCO。

一句话结论：普通用户跟着套餐走、用双栈、能 NAT 就 NAT，别自己下场买段；只有真正需要几百个以上 IP 的大玩家，才值得去二级市场谈批量转让。

常见热点问题解答 (FAQ)

为什么 IPv4 地址会涨价而不是降价？

因为五个注册局的免费池全部耗尽，新地址只能从二级市场买或租，供给刚性、需求却随云和 AI 基建持续增长，价格自然只涨不跌。

2026 年一个 IPv4 大概多少钱？

买断约 15–35 美元/IP，租用约 0.30–0.55 美元/IP/月；大段单价更低，小段（/24）流动性好反而略贵。

VPS 商家收我 2–3 美元/IP 是不是太黑了？

不算离谱。裸租市场价虽低，但商家还要承担清洗、风控、PTR、合规转移等成本，2–3 美元是含服务的打包价，跟商业模式有关。

个人站长有必要自己买 IPv4 段吗？

完全没必要。买断一次性投入大、运维麻烦，跟着套餐租或改用 NAT/双栈更划算，买段只适合需要成百上千 IP 的大客户。
