先别慌：你的 VPS 到底是哪种"被封"？

SSH 连不上、代理打不开，第一反应往往是"IP 被封锁了"。但90% 的"连不上"其实分三种完全不同的情形，处理方式天差地别。混淆它们，轻则白花换 IP 的钱，重则把还能用的机器直接重装。先把三种状态分清，是本篇的灵魂角度。

情形一：IP 被封锁（网络防火墙 封锁，国内不通国外通）

这是真正的"被封锁"。网络防火墙 在国家级出口把你的 IP 整体丢包——国内任意节点 ping 全是超时（Request timed out），但在国外、或用手机流量却秒通。典型表现：ping.chinaz.com 国内全红、itdog.cn 海外节点全绿。这种情况必须换 IP 才能恢复，改端口、重装系统都没用。

情形二：端口被封（IP 通、端口不通）

IP 本身没被封锁，但 SSH（22）或你的代理端口被针对性封锁。验证方法：tcp.ping.pe 输入 IP:22，结果显示国内 failed、国外 successful。此时 IP 能 ping 通，只是某个端口不通。不必换 IP，把服务改到冷门高端口（如 443、或是 20000+ 的随机端口）即可绕过，零成本。

情形三：商家封机（TOS 违规 / 滥用被 suspend）

这跟 网络防火墙 无关，是商家侧把实例挂起（suspended）。常见原因：发垃圾邮件、跑违规流量、CPU 长期 100%、欠费。面板里机器状态变成 Suspended，发工单常收到 TOS 警告。这类情况换 IP 没用，要联系客服申诉、迁移数据，或换一家规则更宽松的商家。

一句话区分：国内不通国外通 = IP 被封锁（换 IP）；IP 通但端口不通 = 端口被封（改端口）；面板显示 Suspended = 商家封机（找客服）。先诊断，再动手，别一上来就花钱。

3 分钟自测：怎么确认 IP 真的被封锁了？

在花一分钱之前，用下面这套流程把"三态"钉死。多数情况 3 分钟内能下结论。

工具清单

  • ping.chinaz.com（站长工具）：选"国内"多个节点 ping 你的 IP，看是否普遍超时；同时可切"海外"对比。
  • itdog.cn（ITDOG）：更直观的国内外多节点 ping + TCP 端口探测，一键生成报告图，适合发给客服。
  • tcp.ping.pe：专门做"IP:端口"的国内外连通性对比，区分"IP 通 / 端口不通"的利器。
  • bwhstatus.com：搬瓦工用户看线路实时状态，确认是不是机房整体抖动。
  • KiwiVM → Test Main IP：搬瓦工专属，直接返回 IP NOT BLOCKED 或 BLOCKED，最权威。

换了 IP 还是被封锁？端口被封怎么办

如果你确认是"端口被封"而非"IP 被封锁"，换 IP 是白花钱。两招零成本解决：

改 SSH / 代理端口

把 SSH 从 22 改到 /etc/ssh/sshd_config 里的 Port 23456（记得放行防火墙），代理服务同理改用 443 或 20000+ 高位端口。网络防火墙 对单端口的封锁远比对整 IP 的封锁常见，改端口能立刻恢复。

KiwiVM Root Shell 绕过端口限制

搬瓦工用户若 22 端口被封连不上，可用 KiwiVM 面板的 Root Shell / Interactive Shell 直接在浏览器里操作，先改端口再重启 SSH，无需通过被封的 22 端口。

治本：换线路比换 IP 更重要

换 IP 是"治标"，真正降低再被封锁概率的是换线路 + 换 IP 属性。这里有几个新手极易踩的混淆点。

网络防火墙 封的是 IP，不是线路——但 premium 线路 IP 更干净

要明确：网络防火墙 封锁的单位是单个 IP，不是"CN2 GIA 这条线"。但 premium 线路（CN2 GIA / AS9929 / CMIN2）的 IP 池通常更干净、更少被滥用，间接更不容易被封锁。换句话说，线路本身不被封，但好线路的 IP 池"出身"更正，被连坐的概率低。

原生 IP vs 广播 IP：为什么换 IP 要选原生池

  • 原生 IP（Native IP）：注册地 / 广播地 / 物理机房三者一致（如洛杉矶机房拿到美国本地运营商 IP）。信任度高，易解锁流媒体，适合电商 / 社媒 / 风控场景。DMIT 全系原生 IP；搬瓦工美国机房也以原生为主。
  • 广播 IP（Announced / BYOIP）：IP 段注册在 A 地、经 BGP 广播到 B 地机房使用（如香港机房广播美国 IP）。便宜、供货量大，但易被流媒体 / 风控识别为代理，被封锁概率可能更高。

对"被封锁自救"的启示：换 IP 时优先选原生 IP 池的商家（DMIT、Bandwagon 美国机房），广播 IP 段被封锁后换了也可能很快再被封。

4837 不是精品线：CN2 GIA / AS9929 / CMIN2 才是抗晚高峰主力

线路排名（抗晚高峰拥堵，注意这是"抗拥堵"不是"抗封锁"）：CN2 GIA > AS9929 / CN2 GT > 163 / AS4837。⚠️ 4837 是联通普通民用骨干（≈电信 163），绝不是"精品线路"，新手常被"4837 优化"话术误导。真正抗晚高峰的是电信 CN2 GIA、联通 AS9929、移动 CMIN2。

商家封机（TOS / 滥用）自救

如果面板显示 Suspended，先别急着重装。步骤：① 看邮件里商家给的封机原因（TOS / 滥用 / 欠费）；② 在工单里如实说明情况、承诺整改，多数商家首次违规会解封；③ 若确认违规严重或商家不松口，先把数据打包迁移出来（rsync / 快照），再换一家规则更宽松的；④ 长期跑代理 / 大流量，优先选对"用途"更包容的商家，并在多个商家之间分散风险。

防封指南：别让新 IP 再废掉

  • 协议伪装：用 Trojan / V2Ray（VMess+TLS / VLESS+Reality）做流量伪装，裸 SS 最易被识别。
  • 控制并发与流量：单一 IP 长期跑满带宽、短时间海量连接，最容易被算法盯上。
  • 监控 IP 状态：用 itdog 定时探测国内连通性，早发现早换，别等彻底失联。
  • 不要滥用：不发垃圾邮件、不刷量、不挂违规业务，TOS 违规比 网络防火墙 更致命。

换 IP 之后别急着切：新 IP 必做的一件事

换 IP 之后不要立刻把所有客户端、节点配置一次性切过去。新 IP 是随机分配的，可能本身就在某个被污染的段里，所以务必先到 itdog.cn 上确认国内三网（电信 / 联通 / 移动）都能通，再批量更新。以搬瓦工为例，换 IP 后旧 IP 会被回收、数据不丢，但绑定旧 IP 的 TLS 证书、防火墙白名单、服务商回调地址需要手动改成新 IP，否则会出现"能 ping 通却连不上服务"的假死。把"换 IP → 测三网 → 改绑定 → 再上线"写进你的固定清单，能省下第二次排查的时间。

总结：先诊断 → 再换 IP → 最后换线路

遇到 VPS 连不上，记住三步法：第一步诊断，用 ping.chinaz / itdog / tcp.ping.pe 分清是 IP 被封锁、端口被封还是商家封机；第二步换 IP，按上表找最便宜的换 IP 通道（DMIT 15 天免费、Vultr 删建即换最灵活）；第三步换线路，长期稳定靠 premium 线路 + 原生 IP 池，别在同一个被污染的 IP 段里反复横跳。把这个流程存下来，下次 IP 再废，照着做就行。

常见热点问题解答 (FAQ)

IP 被封锁后哪些商家还能免费换 IP？

2026 年 DMIT 每 15 天免费换 1 次（需服务剩余 >30 天、自助在面板网络页操作），Vultr 删实例重建即换最灵活；搬瓦工早已取消免费换 IP，被封锁后纯付费（$5-8/次）。RackNerd 部分套餐购后 72 小时内可免费换 1 次，过期收费。选商家时把“换 IP 政策”列入决策：常换 IP 需求大的，优先 DMIT、Vultr 这类换 IP 友好型。

端口被封但 IP 没被封锁怎么办？

把 SSH / 代理改到 443 或 20000+ 高位端口即可零成本绕过，网络防火墙 对单端口的封锁远比对整 IP 常见。改完记得同步更新防火墙、隧道配置和客户端的端口，并用 itdog/tcp.ping.pe 验证新端口国内可达。若 443 也被针对性封，可换非标高位端口或叠加协议混淆。端口层面问题基本都能靠改端口解决，不必急着换 IP 花钱。

换 IP 后还被封锁，是不是白换了？

多半是换到了同一污染段，或本来就是端口被封而非 IP 被封锁。换 IP 前先用 itdog / tcp.ping.pe 分清“IP 被封锁”（三网 TCP 不通）还是“端口被封”（仅特定端口不通）。若是污染段连坐，多换几次或换机房/运营商段才有效；若是端口问题，改端口比换 IP 更省钱。别盲目花钱换 IP，先诊断再下手。

换 IP 之后第一件必须做的事？

先到 itdog.cn 确认国内三网（电信/联通/移动）TCP 都能通，再改 TLS 证书、防火墙白名单、服务商回调地址、DNS A 记录里仍绑定旧 IP 的地方，否则会“能 ping 通却连不上”。同时更新隧道/代理客户端的 endpoint，并重测晚高峰可达性。换完别急着跑业务，留 10-30 分钟观察三网，确认稳了再切流量，避免连环故障。

怎么降低再次被封锁的概率？

治本是换 premium 线路（CN2 GIA / 9929 / CMIN2）+ 原生 IP 池，这类线路被封锁概率远低于普通广播段。再叠加协议伪装（如 VLESS+Reality、Trojan）、控制并发与流量特征、定时用 itdog 监控 IP 状态、被异常马上切。避免一台机器挂太多账号、别用被标记的端口。把“线路质量 + 协议隐蔽 + 监控”三件套做齐，复网络封锁率能显著下降。
