用 VPS 建站，最常见的错误不是买贵了，而是把钱花在 CPU 核数上，却卡在内存和带宽上。WordPress 跑一个动态请求，CPU 占用通常不到 5%，而 PHP 进程池、MySQL 缓冲池、对象缓存会实打实吃掉 500MB 到 1GB 内存。这篇文章把「什么配置够用」拆成可计算的公式，而不是给你一句「推荐 2 核 4G」。

一、WordPress 的配置下限比宣传的高

据腾讯云开发者社区 2026 年 11 月的 WordPress 选型表，WordPress 本体加 MySQL 数据库在空载时占用约 500MB 内存，剩余内存才是留给 PHP 进程池和页面缓存的。该文档给出的结论很直接：内存低于 2GB 时，安装主题、批量更新插件这类操作容易触发 PHP 内存上限报错，2 核 2GB 是合理下限，不建议从 1GB 规格起步。

而萤光云 2026 年 5 月给出的口径略宽松：入门级（日 UV 500 以内）用 1 核 1GB / 20GB SSD / 5Mbps 即可，Nginx + PHP-FPM + MySQL 实际占用约 300–500MB，还能剩一半余量。

两套数据并不矛盾，差异在于「跑得动」和「改得动」是两件事：1GB 能扛住日常访问，但你在后台装插件、生成缩略图、跑备份时会被 OOM Killer 杀掉 MySQL 进程。预算允许就直接上 2GB，这是整篇文章里最省事的一条建议。

三、带宽怎么算：一个公式解决

很多人买机器时只看「带宽 100Mbps」，却不知道自己的站到底吃多少。腾讯云给的估算方式是：

所需带宽 ≈ 页面平均体积 × 并发访客数 ÷ 期望加载时间

举例：首页体积 1.5MB（约 12Mb），希望 3 秒内加载完成，单个访客就需要约 4Mbps。带宽不足的典型表现不是「打不开」，而是图片一块一块地刷出来——因为 HTML 先到了，图片还在排队。

月流量则更简单：页面平均体积 × 月均页面浏览量。同样是 1.5MB 的页面，月浏览量 1 万次约消耗 15GB 流量，10 万次就是 150GB。海外低价 VPS 动辄给 1–2TB 月流量，对绝大多数个人站来说是彻底过剩的——真正的成本在内存，不在流量。

四、静态站、动态站、全栈：三种建站路线

  • 纯静态站（Hugo / Astro / VitePress）：不需要 PHP 和数据库，1 核 512MB 都能跑，还能直接丢到 Cloudflare Pages、GitHub Pages 这类免费服务上。想省到底，可以先看 纯 Serverless 免费边缘栈 与 GitHub Pages + Cloudflare 建站流程。
  • 动态站（WordPress / Typecho / Halo）：必须常驻 PHP-FPM 与 MySQL，内存下限 2GB 起，适合需要后台编辑、插件生态、评论互动的场景。
  • 容器化全栈（Docker Compose 拉博客 + 数据库 + 监控）：单机就能复现生产环境，代价是多 200–400MB 内存开销，建议 4GB 起。部署方式见 Docker Compose 一键拉起全家桶。

选路线比选商家重要。一个日更 300 字的个人博客，用静态站 + 免费托管，成本和稳定性都优于任何一台年付 10 美元的 VPS；反过来，需要 WooCommerce 收款、需要会员系统的站，静态方案根本做不了。

五、省钱三件套：Opcache + Redis + CDN

同样一台 2 核 2GB 的机器，优化前后能差出一个配置档：

  • Opcache：把 PHP 编译结果缓存在内存里，动态站必开，能砍掉一半以上的 CPU 开销；
  • Redis / APCu 对象缓存：WordPress 装上 Redis Object Cache 后，数据库查询次数能降一个数量级，这是低配机器最划算的一步；
  • CDN：把图片、CSS、JS 全部推到边缘节点，源站只需要返回 HTML，带宽压力瞬间归零。Cloudflare 免费版就够用，配置思路见 Cloudflare 免费全家桶。

这三件事做完，1 核 1GB 跑日 UV 300 的博客是没问题的——但请仍然留出 2GB 的余量给后台操作，别把「跑得动」当成「够用」。

六、建站最容易踩的四个坑

  • 拿普通国际 BGP 做面向国内的站。据华纳云 2026 年 10 月的线路实测，普通 163 骨干线路在香港机房晚八点到十一点延迟可从 50ms 跳到 180ms 以上、丢包 5%–10%。程序再快也没用，详见 国际 BGP 线路专题。
  • 忽略续费价。低价年付套餐的「首年 $10」和「续费 $10」是两回事，下单前一定看清续费条款。
  • 没有异地备份。VPS 商家的快照不是备份，磁盘挂了快照一起没。至少每周用 restic 或 rclone 同步一次到对象存储；备份策略见 自建私人云盘。
  • 不装监控。站点挂了两天才发现是最常见的运营事故，用 Uptime Kuma 自建告警，十分钟能配完。
