二、Oracle Cloud Always Free：目前唯一「规格能打」的永久免费机

Oracle 的 Always Free 至今仍是公有云市场里最慷慨的一档真·永久免费资源——没有到期日，也不需要持续扣费。2026 年的配额如下（据 Vuncloud 2026-09 与本站 2026-08 的核对）：

资源额度说明
ARM 计算（Ampere A1）2 OCPU + 12GB 内存可拆成一台 2 核 12G，或两台各 1 核 6G
AMD 微型实例最多 2 台（1/8 OCPU + 1GB）可突发到整核，适合 DNS / 监控 / 定时任务

2026 年最重要的变化：免费 ARM 额度已从早年的 4 OCPU / 24GB 正式砍半到 2 OCPU / 12GB（约 2026-06-15 起对新账户生效）。纯 Always Free 账户只能拿 2C12G；升级成 Pay As You Go 才保留旧的 4C24G。网上流传的「4 核 24G 教程」属于历史红利，新号强行开会产生扣费账单。

除了配额，还有三个现实问题：注册像抽卡（能不能注册成功、能不能抢到 ARM 实例都是概率事件）、容量不足（热门区域常年 Out of capacity）、闲置回收（长期低负载的免费实例可能被停）。所以正确的定位是：Oracle 永久免费完整指南 里那句——把它当副驾、当练手环境、当备份节点，别当生产主力。

三、Google Cloud e2-micro：第二台真·永久免费机，但有硬限制

GCP 的免费档是一台 e2-micro：共享 2 vCPU（可突发）、1GB 内存、30GB 标准盘，永久免费，但只能开在 us-west1、us-central1、us-east1 三个美国区域。

它最容易被忽略的限制是出站流量只有约 1GB/月（中国大陆、澳大利亚等区域除外）。1GB 是什么概念：一个 1.5MB 的页面，月访问 600 次左右就打满了。所以 e2-micro 的正确用法是只做内网服务、定时任务、CI runner、DNS，不要拿它对外提供网页。申请流程见 GCP 免费 e2-micro 手把手申请。

四、这些「免费 VPS」其实不是永久免费

  • AWS Free Plan：额度制，最多 $200、最长 6 个月，到期关户。不是常开机器。详见 AWS 免费套餐全攻略。
  • Azure 免费账户：B1s 等 12 个月小时包 + $200/30 天信用额度，30 天内不升级 PAYG 就停。
  • GCP 试用金：约 $300 / 90 天，试用会过期。
  • DigitalOcean：约 $200 / 60 天，没有永久计算档，最便宜 Droplet 约 $4/月。
  • Vultr：约 $250 / 30 天促销，促销随时变，到期按量计费。
  • 国内轻量「0 元体验」：多数 7–30 天，过期转付费，且常有新客与地域限制。

这些不是「骗」，但它们的正确叫法是试用金。如果你打算长期跑一个服务，用完额度就得迁移——迁移成本往往比直接买一台 $10/年的机器更高。

五、会休眠的「免费云」：不是 VPS

Render、Koyeb、Railway、Hugging Face Spaces 这类平台经常被归进「免费 VPS」，但它们本质是 PaaS 容器：

  • Render Free：0.1 CPU / 512MB，无持久盘，750 实例小时/月，空闲约 15 分钟休眠，免费 Postgres 30 天过期；
  • Koyeb Free：0.1 vCPU / 512MB / 2GB SSD，每组织 1 台，空闲 1 小时缩到零，仅 FRA 或 WASH 区域；
  • Railway Free：最多 1 vCPU / 0.5GB，卷最大 500MB，超额度即停；
  • Hugging Face Spaces（CPU Basic）：2 vCPU / 16GB，约 50GB 临时盘，空闲约 48 小时休眠，不是通用 VPS。

冷启动按分钟计，这对 Webhook、Telegram Bot、监控探针这类需要秒级响应的场景是致命的。真要用，就把它当「静态站 + 偶尔触发的函数」，别当服务器。

六、免费 VPS 的五个坑（每一个都有人踩过）

  1. 把试用金当永久免费。第 181 天机器被关，数据没备份，这是最常见的翻车方式。
  2. 忘了出站流量要钱。GCP e2-micro 只有约 1GB/月，Oracle 是 10TB/月，两者差 1 万倍。跑之前先算清楚。
  3. ARM 架构不兼容。Oracle 免费机是 Ampere A1（ARM64），x86 的二进制、部分 Docker 镜像、某些商业面板跑不了。部署前确认有 arm64 构建。
  4. 闲置被回收。Oracle 会停长期低负载的免费实例，重要数据必须异地备份。
  5. IP 信誉不干净。免费档的公网 IP 被滥用得多，注册第三方服务、发邮件、跑电商容易被风控。上线前先跑一遍 IP 纯净度检测，看诈骗分与黑名单。

❓ 常见问题

2026 年还有真正永久免费的 VPS 吗？

有，但只剩两家：Oracle Cloud Always Free（ARM 2 OCPU + 12GB 内存、200GB 块存储、10TB/月出站）和 Google Cloud 免费套餐里的 e2-micro（共享 2 vCPU、1GB 内存、30GB 盘）。其余标着「永久免费」的多数是 30–180 天的试用额度，或者会休眠的 PaaS 容器。

Oracle 免费 ARM 现在是 2 核还是 4 核？

新账户是 2 OCPU + 12GB 内存（约 2026-06-15 起生效），只有升级成 Pay As You Go 的付费账户才保留旧的 4 OCPU + 24GB。网上传播的 4C24G 教程属于早期历史红利，新号强行开机会产生扣费账单。

免费 VPS 能用来建站吗？

能，但要挑。Oracle 的 ARM 机配 10TB/月出站流量，跑个人博客、反向代理、Vaultwarden 完全够；GCP e2-micro 只有约 1GB/月出站，只适合内网服务。两者的共同短板是 IP 可能变、可能被回收、线路不受控，所以商业站建议用一台年付 $10 左右的机器兜底，免费机只做学习或备线。

免费 VPS 会不会突然扣费？

免费档本身不扣费，风险来自三处：手滑创建了付费（PAYG）机型、超出免费额度的块存储或出站流量、以及试用金到期后未及时降级。避免方式很简单——在控制台设一个预算告警，并每月核对一次账单页。

免费机被回收了怎么办？

只能重建，所以关键在于「能重建」：把系统配置写成 Docker Compose 或 Ansible 脚本，数据用 restic / rclone 定时同步到对象存储（Cloudflare R2 有 10GB 免费额度，Backblaze B2 约 $6/TB/月）。做到这两点，机器被回收的损失就是二十分钟。
