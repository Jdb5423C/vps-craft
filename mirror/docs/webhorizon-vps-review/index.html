# 一、产品结构：三条线、一个新加坡、一半缺货

WebHorizon 主站是 webhorizon.in，客户中心在 clients.webhorizon.net，面板用 Blesta 而非更常见的 WHMCS：账单、工单、续费的层级完全不同，第一次登录会找不到「我的服务」，属于纯粹的熟悉成本。

# 二、核心：NAT 与独立 IPv4，差的不是一个地址

一台 NAT VPS 自己没有独立公网 IPv4。宿主机把少数几个公网地址共享给几十台虚拟机，通过 DNAT 做端口映射，商家分给你一段固定端口（业内常见 20 个），外部访问必须写成 IP:端口。IPv6 通常独立，给 /64 或 /48，可直连。独立 IPv4 则相反：地址只属于你，全端口可用（商家可能仍封 25），PTR 可自设，信誉由自己决定。

共用 IP 的连带风险有六条：

一是封 IP 会连坐。 同 IP 上只要有人发垃圾邮件、跑扫描、撞库被投诉，整个 IP 就会进黑名单。你什么都没做，但域名被拦、验证码刷不完、API 回调失败——后果由整台 IP 上所有人共同承担，而你无从知道邻居是谁、有几个、在干什么。

二是被Q也是连坐。 独立 IP 被封是「我这一台出事」，NAT 的 IP 被封是「这一批人一起出事」。绝大多数 NAT 机型不提供免费换 IP，商家也没有义务为邻居的行为买单。

三是端口是有限资源。 你只有分配到的几个端口，80 与 443 通常不在其中。建站必须套 CDN、做反代，或改用高位端口——对普通访客不可接受。部分商家还限制 UDP 或可映射端口数量，游戏与部分 P2P 协议直接卡死。

四是邮件基本别想。 共享 IP 的 PTR 不归你，25 端口通常被封，SPF、DKIM 配得再标准也难投递。用 NAT 机发事务邮件是自我折磨。

五是做不了 IP 白名单。 支付网关、银行接口、部分企业 SaaS 需要固定出口 IP，NAT 机接不上，因为你无法证明「这个请求来自我」。

六是信誉不透明。 独立 IP 还能查历史黑名单；NAT 的 IP 几十人共用，今天干净不代表明天干净，风险动态变化，你没有观测手段。

差价从哪来？IPv4 早已是稀缺资产，一个独立 IP 的月成本通常在 $1 ~ $3。NAT 把这笔钱整笔省掉，便宜不是魔法，是不给你独立 IP。
