ColoCrossing 的自治系统号是 AS36352，官方公布的上游包括 Arelion（Telia）、GTT、Cogent、Hurricane Electric。这几家都是 Tier 1 / 大型传输商，意味着它的国际出口不是单一运营商单线，而是多线 BGP 冗余。对低价 VPS 来说，这是最实在的一项底层福利：你花几美元买到的机器，出口带宽的「批发价」是按大客户算的。

也正因为如此，ColoCrossing 的主营业务从来不是「卖给个人一台小鸡」，而是把机柜、电力、带宽和 IP 段批发给服务器租赁商与托管客户。它自己建机房、自己拉光纤、自己维护边界路由，然后把资源切成不同颗粒度转售。你在终端看到的品牌是 RackNerd、CloudCone、DediRock 还是别的名字，在网络层看到的往往都是同一个 AS36352。

这一点在第三方实测里有很直接的旁证：WakServer 在洛杉矶一台 4GB 机型的评测中记录到 AS36352 HostPapa，同时 Host 字段显示 RackNerd LLC（数据来源：WakServer（https://wakserver.com/los-angeles/colocrossing-4gb-ram-vps-3-49-month），采集于 2026-11-07）；站内 DediRock 洛杉矶 $7/年 的测评 里，ISP 一栏同样写着 HostPapa、ASN 写着 AS36352。同一张网、不同招牌，这就是低价 VPS 生态的常态。

在这个结构里，「二道贩子」并不是贬义词，它是机房批发模式的正常一环。分销商向 ColoCrossing 租母机或整柜，再自己切 KVM、自己定价、自己做客服。你多付的那部分钱，买到的是选品能力、售后响应和支付便利，不完全是「智商税」。

反过来，直销的优势是少一层加价、账单关系更直接；劣势是你直接面对机房的标准化流程——工单按队列走、退款按条款走、特价机按库存走，很少有分销商那种「帮你换个 IP、给你补几天」的灵活度。

# 3. 对买家的三个实际影响

  • 网络成熟，但「邻居」复杂：自建机房意味着电力、制冷、边界路由有人管，不会像小作坊一样说跑就跑；但低价段被大量滥用过的历史，会让部分 IP 在风控数据库里带「前科」。第三方测评里能看到同一个 ASN 下不同 /24 的欺诈分从个位数到 40 分不等，IP 质量要按段看，不能按商家看。
  • 售后是「机房级」而非「管家级」：ColoCrossing 的工单更像基础设施工单，讲证据、讲条款，不太会给情绪价值。社区里有用户因「不限流量」描述与实际 20TB 不符而开工单、最终客服修改了流量配置的案例——这属于个案协商，不是政策承诺（详见第五节）。
  • 直销与分销不是替代关系：如果你要的是「一台便宜、能开票、能支付宝」的机器，直销足够；如果你要的是「有人帮你选机房、出问题有人兜底」，分销商反而更合适。别把「上游」自动等同于「更好」。

💡 一句话理解：ColoCrossing 是「卖面粉的」，也自己开了一家面包店。面包店的面包确实可能更便宜，但品种、出炉时间和退换规则，都是它说了算。

# 1. 四个机房怎么选

水牛城（纽约州） 是总部所在地，也是大量特价机的默认落点。它的优势是「机房自己的地盘」，库存最稳、补货最快；劣势是对国内用户来说，美东的物理延迟天然比美西高。第三方测评（VPS之家）在纽约入门款上测得全国平均延迟约 232ms，电信 192–273ms、联通 182–295ms、移动 220–295ms，三网回程分别是电信 163、联通 4837、移动 CMI，都是普通国际线路，没有 CN2 GIA 一类的优化。这个成绩对美东机房属于正常水平，建站套 CDN 可用，直连打游戏不行。

芝加哥 位于美国中部，是全美骨干的交汇点之一。第三方测评（美国主机侦探）在同款入门机型上测得国内三网平均延迟约 230ms，国内上传约 100Mbps、下载约 180Mbps，而芝加哥本地与美国东岸的上传能到 650–760Mbps。它更适合「服务美国本土用户」而不是「服务国内用户」。

以上延迟与吞吐数据来源：VPS之家（https://vpszhijia.com/colocrossing-%E7%BA%BD%E7%BA%A6%E6%9C%BA%E6%88%BF%E6%B5%8B%E8%AF%84）、美国主机侦探（https://www.idcspy.com/124794.html），采集于 2026-11-07。第三方实测受时间、机房、运营商与库存影响，本站未复现；套餐与网络条件以商家实际业务为准。

达拉斯 是南部枢纽，适合做全美多节点探针、API 中转与灾备。对国内来说延迟介于美西与美东之间，优势是到南美与美东的连通性较好。

洛杉矶 是国内用户默认最该先测的一个。它离亚太最近，物理延迟最低，适合建站、代理与文件中转。但要注意：洛杉矶节点在促销款里不一定开放，很多 $1.97 / $10.99 的特价机被锁定在美东，下单时务必在结算页确认可选机房。

# 2. 几个容易被忽略的细节

  • 默认无 IPv6：官方知识库把「IPv6」单独列为一条说明，多篇第三方测评与本站记录均指向默认不提供 IPv6。如果你的业务依赖 IPv6（比如某些邮件、爬虫、容器网络场景），下单前先开工单确认，不要假设「大厂一定有」。
  • 换 IP 有成本：第三方测评记录显示，ColoCrossing 更换 IP 一次约 3 美元。对需要频繁换 IP 的业务，这是一笔持续成本。
  • 「1Gbps」是端口速率，不是保证带宽：共享母机上的实际吞吐取决于邻居、时段与对端。第三方实测里，标称 1Gbps 的机型在全球 iperf3 测试中经常只有 200–500Mbps，这是低价机的常态，不是故障。

⚠️ 以上 IP 与测速文件均来自商家官方页面，「来源可核实」不等于「当前一定可达」。LG 节点可能临时维护，测速文件也可能调整路径，请自行验证后再下单。

# 套餐选择的三个直觉

  • 单价最低 ≠ 单位性价比最高：$1.97 的 1GB 款是「入场券」，每 GB 内存成本并不低；$22.5 的 16GB 款、$12.47 的 8GB 款，单位内存价格明显更划算，适合跑多个容器或做内存型缓存。
  • 年付 40TB 线是「流量套利」：$10.99/年 给 40TB/月，折合每 TB 流量不到 3 美分。如果你的用途是流量型（中转、冷备、图床、离线下载），这条线比月付五折线更值；但它的 CPU 与磁盘依旧是入门级，别指望跑重活。
  • 标准月付买的是「选择权」：多花几毛钱，换来多机房可选与更稳定的库存。当你明确需要洛杉矶或达拉斯时，优先看标准线，而不是在特价线里赌机房。

💡 一个反常识的结论：ColoCrossing 的特价机不是「配置缩水的残次品」，而是「把机房选择权和性能上限砍掉，换取价格」的产品。你省下的钱，本质上是用不确定性买单。

# 四、$1.97 的另一面：低价款的七个真实限制

这一节是全文最该细看的部分。$1.97/月 听起来像白送，但它的限制都写在「没写出来的地方」。

# 1. 机房被锁在美东

cc-50off-monthly-* 六款的机房字段统一标注为美东（US_EAST），假日季 40TB 线同样如此。如果你需要洛杉矶，这些价格与你无关。对国内用户，美东意味着 200ms 起步的物理延迟，晚高峰的抖动也更明显。低价的第一层代价，是地理位置的妥协。

# 2. 单核性能是「够用」而非「好用」

第三方实测里，ColoCrossing 低价机型常见的 CPU 是 Intel Xeon E5-2683 v4（2.1GHz）与 Xeon Platinum 8176（2.1GHz）。同一份 WakServer 实测中，洛杉矶 4GB 款测得 Geekbench 6 单核 277、多核 527——这个单核成绩属于「能跑系统、能跑轻容器，但编译、转码、数据库查询会明显吃力」的水平。

这不是个例，而是低价 Xeon 平台的共性：主频低、单线程弱，多核靠堆 vCPU 补。你买 8 核 16GB，得到的不是「8 个快核」，而是「8 个慢核」。

# 3. 磁盘顺序读写还行，4K 随机很弱

同一份实测里，bench.sh 的顺序 I/O 平均约 315MB/s（另有芝加哥测评记录到 624–750MB/s，说明不同母机差异很大），但 YABS 的 4K 随机写只有约 21MB/s（约 5.3k IOPS）。这意味着：

  • 放大文件、做冷备、跑静态站：没问题；
  • 跑 MySQL / PostgreSQL、跑大量小文件读写的应用：会明显卡。

「SSD」不等于「快盘」，低价机的 SSD 往往是 SATA 或低配 NVMe 共享阵列，看 4K 随机比看顺序速度更有意义。

# 4. 1Gbps 是端口上限，不是实测吞吐

WakServer 的 iperf3 测试显示，这台标称 1Gbps 的机器在洛杉矶本地约 598/208Mbps、伦敦 283/95.7Mbps、新加坡 270/98.7Mbps；nws.sh 全球 Speedtest 平均下载约 189Mbps、上传约 243Mbps。「跑不满」是常态。

国内方向更明显：美国主机侦探在芝加哥款上测得国内上传约 100Mbps、下载约 180Mbps。如果你要的是「中美大带宽传输」，这台机器给不了你 1Gbps 的体验；它给的是「不限总量、但单流有限速感」的通道。

# 5. 默认无 IPv6，换 IP 要花钱

官方知识库把 IPv6 单列一条，第三方测评与本站记录均显示默认不提供；换 IP 一次约 3 美元。对需要大量独立 IP 或 IPv6 的业务，这两条会直接改变成本结构。

# 6. 库存与价格都不稳定

66 款里只有 11 款明确标 available，52 款「未标注」、3 款 unknown。促销款经常是「上一批卖完、下一批换配置」。你看到的 $1.97 可能明天就变成 $3.95，或者干脆下架——这不是商家耍猴，而是机房按批次放库存的正常节奏。

# 7. 特价机通常不参与优惠码，也不退款

这是最容易被忽略的一条：特价机本身就是「折后价」，后台往往直接关闭了优惠码入口；同时官方对 Cloud VPS 一律不退款。两者叠加，意味着你下单那一刻，试错成本就已经沉没。

# 谁适合这台机器？

  • 适合：离线下载与中转、rclone 冷备、探针与监控节点、轻量 Docker（Pi-hole、Uptime Kuma、Vaultwarden）、静态站与个人博客（套 CDN）、美国本土 API 中转。
  • 不适合：生产数据库、游戏服务器、视频转码、重载 WordPress、国内直连的低延迟业务、需要 IPv6 的业务、需要「不满意就退」的用户。

💡 判断口诀：如果这台机器挂了，你的业务会不会「立刻出事」？会——别买；不会——可以买。低价机的正确用法，是把它放在架构里「可替代」的位置。
