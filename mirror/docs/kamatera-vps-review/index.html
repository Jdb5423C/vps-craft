# 一、它卖的到底是什么：配置积木，而不是套餐

# 1. Type A 与 Type B 是两种商品

Kamatera 的 CPU 分两类，这是理解其全部定价的钥匙：

  • Type A（Availability）：共享型，vCPU 不保证独享线程，高负载时与邻居抢资源；$4 与 $19 两档按数据库备注归入此类。
  • Type B（General purpose）：官方称线程独享、资源预留，面向生产级 Web、API、中等数据库。$25 与 $39 两档属于这一类。

这条差异比核数更重要。同样是 2 核 2GB，$9 与 $25 差的不只是 16 美元，更可能是线程是否独享——把它们并列成「同配置不同价」，是常见误读。

# 2. 计费粒度是分钟，不是小时

官方定价页 FAQ 原话是 hourly servers are billed by the minute：跑 40 分钟就只算 40 分钟，不向上取整到 1 小时。

官方同时给出两个附加单价：额外流量 $0.01/GB，额外存储 $0.05/GB/月。这解释了「$4 起」为何容易变成「$15 起」：多加 100GB 盘就是每月多 5 美元。

# 3. 「可配置」的副作用是所有比价都失真

固定套餐商之间可以逐档对齐，Kamatera 不行。本文的 5 档价格只能理解为官方配置器预设组合的标价，不是同等性能的市场价；真要对比，请拿同一份清单两边各算一遍。

# 三、计费、试用与扩容：三件容易误判的事

# 1. 月付是预付费，取消不退当月

官方 FAQ 写明：创建月付服务器时预付一个月费用，升级按比例补差价，终止时需支付「取消发生的当月」费用，次月起不再扣款。也就是月中取消，当月那笔钱不按剩余天数退。这与「按小时计费、停了就不算」是两套逻辑。

# 2. 30 天试用与 $100 额度，是额度不是现金

官方口径是 30 天免费试用、最高 $100 服务额度、限 1 台服务器。第三方补充了一个关键细节：试用需绑定有效信用卡激活，到期未终止会自动转为付费（数据来源：HostAdvice，https://hostadvice.com/hosting-company/kamatera-reviews/，采集于 2026-11-07）。

这把「免费试用」变成了需要主动收尾的动作：到期前必须自己终止实例，否则信用卡开始正常扣费，官方又不退款。

# 3. 扩容即时，账单也即时

可以随时升降配，不用迁移、不用重装，升级部分按当月剩余时间比例计费，对流量突增场景实用；但它也意味着配置会悄悄变贵：加盘、开备份、多买 IP，账单一项项往上叠，首页并不替你汇总。

💡 控制成本的两个动作：每月固定一天导出账单明细看附加项；所有临时实例在创建时记一条日历提醒，试用与测试机必须手动终止。

# 1. 优点：它确实解决了一类问题

配置自由度是真的高。固定套餐商给你「几选一」，它给你「自己拼」：2 核 16GB 这种畸形配比，或单核配 200GB 盘做归档，别家凑不出来。

# 2. 缺点与不适合人群

它不便宜。 $4 的 1C1G 属于偏贵，同价位年付商能给更高配置；核心诉求是单位算力最便宜的话，它不是答案。

不退款加余额不可提现，容错率极低。 年付商买错损失一年，它是钱进去出不来，且月付取消不退当月。

支付透明度差。 支付宝、微信、银联能否使用，核查后仍是 unknown——对只有国内支付工具的用户，这是硬门槛。

测速与线路都不透明。 只有网页测速，没有可脚本化的 ping 目标；全线 BGP，晚高峰表现取决于运营商互联质量，买后也改不了。

控制台对新手不友好。 第三方把「仪表盘为空、缺少引导、控制项分散」列为主要缺点（数据来源：VPS Scout，https://vpsscout.com/review/kamatera-vps-hosting/，采集于 2026-11-07）。
