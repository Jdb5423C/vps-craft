# 一、先分清「轻量」与「云服务器」

16 条套餐乍看只是配置高低，实际分成两条产品线，命名里藏着关键信息。

产品线存储流量 / 端口命名特征计费含义
轻量云（lite）10 / 30 / 50 / 90GB SSD 或 NVMe500GB900GB，200500 Mbps带「续费同价」续费同价，长期成本可预测
云服务器（intel / amd）15 / 30 / 70GB SSD 或 NVMe600GB~1.5TB，统一 500 Mbps带「8折新购」或纯型号折扣只作用于首次购买，续费回原价

记住：「续费同价」和「8折新购」是两种完全不同的条款——前者买长期价格确定性，后者买首年低价，第二年账单会跳回标价。中文测评里的「XX 元一年」若来自 8 折码，只对第一年成立。

轻量定位「够用就行」：盘小、流量 500~900GB、端口 200~500Mbps，适合单站点与中转；云服务器盘加到 15~70GB、流量 600GB~1.5TB、端口统一 500Mbps，适合面板、数据库与容器。

官方把香港拆成精品、优质、国际三档（第五节三个子域一一对应），但收录的 16 条全部标注「优质 BGP」。本文只能给中间那一档的画像，精品与国际两档没有可核实的价格。

官方把香港分成精品、优质、国际三档，各有一个测速子域（见第五节）。收录的 16 条全是「优质 BGP」，下面数据也只代表这一档。

两组数字差了近 2.5 倍，但不能直接判定谁在吹牛：一份测优质 BGP 的 100Mbps 峰值机，一份测 5Mbps 的普通 BGP 月付机，月份、探测点、档位全不同。它们真正的价值是给出区间感——不同档位延迟能差一倍以上，联通用户尤其容易踩到绕路；联通 188ms 且去程绕新加坡，就是便宜档用国际 transit 兜底的典型。

这与官方上游结构对得上：电信 CTG（AS23764）、联通 CUG（AS10099）、移动 CMI（AS58453），再加 HKIX、Telstra、Hurricane Electric。标准香港多线 BGP，不是 CN2 GIA，但走哪条、绕不绕取决于档位与出口调度。

选购逻辑落到场景：面向国内访客，优质档 40~60ms 是合理预期，晚高峰会抖；只做海外流量或当跳板，国际档更便宜；指望它当 CN2 GIA 平替，会失望。

第三方的「原生 IP」结论未经本站复核；做流媒体、注册类业务前，自己查一遍 IP 信誉库。

💡 线路结论：野草云卖的是「香港多线 BGP 的便宜版本」，不是「回国优化线路」。把它放在对的位置，性价比才成立。
