# 一、德国机房到国内：延迟的变量是绕路，不是距离

先把最容易误解的一点说清楚：德国到中国的物理距离摆在那里，没有任何德国机房能做到「低延迟」。所谓「德国机房访问还行」，说的是路由不绕、丢包可控，而不是快。主力机房在纽伦堡，另有维也纳、阿姆斯特丹。按第三方对纽伦堡一台入门机的实测，国内三网 IPv4 平均延迟大致如下：

运营商较低地区较高地区典型区间丢包观察
电信内蒙古约 145ms西藏约 243ms164~232ms1%~18% 波动
联通安徽约 145ms重庆约 284ms145~305ms多数 0%
移动北京约 145ms陕西约 252ms145~252ms0%~2%

数据来源：StockVPS 博客（https://www.zhichao.org/posts/f6fe96），采集于 2026-11-07。第三方实测受时间、机房、运营商与库存影响，本站未复现；套餐与网络条件以商家实际业务为准。

这组数字的价值在于「量级」：150ms 是运气好，200ms 上下是常态，250ms 以上也不稀奇。回程上电信走 163、联通走 4837、移动走 CMI，都是普通国际线路。同一次测试里，联通与移动的 IPv6 回程甚至绕行美国，末跳被推到 254ms 与 296ms——换一个协议栈，体验可能完全不同。

所以判断标准要换成场景：给欧洲用户建站、跑 API、做邮件服务器、挂 CI，这些对延迟不敏感的业务，德国节点是合理的；指望国内直连秒开，那无论多便宜都不该选它。

💡 一句话预期管理：把 netcup 当成「放在欧洲的机器」，而不是「能加速国内的机器」。

Root Server 与 VPS 的核心差别只有一条：CPU 是否独享。 VPS 卖的是时间片，邻居跑满时你会被调度；Root Server 把物理核划给你，性能下限更稳。第三方整理显示，同为 8GB 内存，RS 1000 比 VPS 1000 贵约 50%，而上一代 G12 的溢价只有 23%——独享核越来越贵了。是否值得，取决于负载怕不怕邻居：MySQL 尾延迟、编译耗时、实时音视频都怕；静态站、轻量 API 完全不必。

VPS Lite 便宜，但代价有三样：不能按小时计费、可用性承诺更低、限速更严。第三方整理的规则是 Lite 按「24 小时平均速率超 100Mbit/s」触发限速，普通 VPS 则「24 小时流量超 2TB」降到 200Mbit/s；100Mbit/s 跑一天约 1TB，Lite 的余量只有普通 VPS 的一半。持续大流量分发别省这几欧。

ARM 线的价值在存储与端口：同为 G12.5，x86 VPS 的存储描述已退化为「SSD」，ARM 仍写 NVMe，且第三方称 ARM 全系配 2.5Gbit/s 网卡。坑在于部分软件没有 aarch64 版本，买前先确认技术栈能跑。

💡 选线顺序：先问负载怕不怕邻居，再问合同能不能锁一年，最后才看价格。顺序反了，便宜就会变成返工。

# 四、IPv6-only 与额外 IPv4：每月省几欧，代价可能是「连不上」

netcup 近两年把 IPv4 从「默认附赠」改成了「可选项」，这是中文用户最容易踩的坑。

按第三方记录，2026 年 1 月起套餐取消 IPv4 后更名，IPv6-only 保持原价，补回 IPv4 需另加 €0.5/月，年付差约 €6；G12.5 代际的口径是 IPv6-only 或仅 Cloud vLAN 每月减 €0.60（不含税）。数据来源：StockVPS 博客（https://www.zhichao.org/posts/f6fe96）与 netcupvoucher 价格整理页（https://netcupvoucher.com/blog/netcup-pricing-2026），采集于 2026-11-07。第三方实测受时间、机房、运营商与库存影响，本站未复现；具体加价以结算页为准。

€0.5 到 €0.6 一个月，看起来是零钱，影响的却是可达性：

  • 国内很多家宽与办公网没有公网 IPv6，IPv6-only 的机器在这些网络里 ping 不通、SSH 也连不上，必须先有 IPv4 入口。
  • CDN 回源、监控探针、第三方回调大量仍只支持 IPv4，省下的 €0.6 可能要拿一台中转机去补，成本更高。

反过来，若你的场景是「欧洲内部服务 + 自己有双栈网络 + 有 IPv4 跳板」，IPv6-only 是干净的省钱方式，还能拿到一整段 /64 做容器网络。

建议很直接：第一次买 netcup 不要选 IPv6-only。 先用带 IPv4 的配置跑通，确认业务真的不需要再切过去。省下的钱不够折腾一晚上。

退款部分更需要冷静。欧盟消费者享有法定 14 天撤回权：自合同订立起 14 天内以书面或邮件声明撤回，商家须在收到通知后 14 天内以原支付方式退款且不收手续费。但这权利有三个硬限制：

  1. 企业/商业客户不适用，注册时填了公司信息就别指望；
  2. 域名注册不适用，且首年费用照付；
  3. 若经你明确要求、合同在撤回前已完全履行，撤回权提前消灭——服务器已开通并投入使用，通常就落进这一条。

还有一点：VPS 不在官方 30 天满意保证（Zufriedenheitsgarantie）的覆盖范围内，那项保证主要针对虚拟主机与 Root Server。有第三方页面在 VPS 产品页挂了「30 天退款」徽章，同页正文却仍写着该保证属于 Root Server，口径矛盾时按「VPS 无此保证」准备更安全。真要退款，走工单与邮件双通道，别在确认前同意删机。

💡 支付结论：这不是一家为中文用户优化过付款体验的商家。卡 + PayPal 是主路，支付宝和微信都不在清单里，别等到下单页才发现。

# 优点

  1. 单位算力价格低：€4 给 2 核 4GB、€5.75 给 4 核 8GB，欧洲同价位里配置扎实。
  2. 产品线分层清晰：共享核、Lite、ARM、独享核四档各有取舍，可按负载选型。
  3. 基础能力不额外收费：快照、备份、DDoS 防护、救援系统、自定义 ISO 都含在套餐内。
  4. 计费与诊断开放：支持按小时计费，官方 Looking Glass 可下单前自查路由。

# 缺点与不适合人群

  1. 支付对中文用户极不友好：支付宝、微信、银联全不在受理清单内，只能走卡、PayPal、SEPA 或电汇。
  2. 国内访问没有优化：普通国际线路，150~250ms 是常态，IPv6 下联通、移动还可能绕美国。
  3. 价格在上行通道：多轮调价后，新订单入门价已明显高于本文的 €4 快照，拿旧价做预算会落空。
  4. 退款边界模糊：法定撤回权附条件，VPS 又不在 30 天满意保证内，官方与第三方表述还存在冲突。
  5. 不适合的人群：面向国内用户的建站者、只习惯支付宝/微信的人、需要中文客服的新手、把退款当试用期的人、需要生产级 SLA 的核心业务。
