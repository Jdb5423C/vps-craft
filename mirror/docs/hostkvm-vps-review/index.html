# 一、三条香港线加一条美国线：先定线路，再定配置

本站库收录 11 条记录，10 条香港、1 条洛杉矶，线路只标 CN2 与 CN2_GIA，没有 CN2 GT、没有 9929——它卖的是「内地方向优化」，不是国际大带宽。

三条线的分工：HKGO 走 HKIX、CTG、NTT 等国际运营商，端口 500Mbps 起、可到 1000Mbps，适合全球访客，但不承诺内地晚高峰。HKCP 是 CN2 GIA + CMI + CUG 三网直驳，电信走精品网、移动走 CMI、联通走 CUG，各走各的通道，是唯一敢写「无高峰期影响」的线。HKCO 接驳 China Telecom Global，定位「内地连得上、成本可控」，是折中方案。

关键细节是回程不对称。第三方路由跟踪显示，这类 CTG 机型三网去程基本直连、电信去程还能走到 59.43 的 CN2 节点，但电信与联通回程存在绕日本、绕美国的情况。你 ping 到的 58ms 是真实的，下载大文件时的吞吐却可能远低于这个数字暗示的水平——延迟看最短的一段，带宽看最堵的一段。

美国线只有一条洛杉矶 China Optimized（2C/4G/1TB @ 50Mbps），价值在「需要美国 IP、又希望内地能连」这个窄场景。真要跑美国业务，可对照 DMIT Pro 系列。

💡 三条香港线不是低中高档，而是三种取舍：要带宽选 HKGO，要晚高峰稳定选 HKCP，要便宜且内地能连选 HKCO。先回答「访客在哪、几点访问」，再看配置表。

# 五、线路质量：58ms 是真的，回程绕路也是真的

两组第三方数据可以互证，但要看清测试条件。猎者出海对一台 2C4G 香港机型的测试：Xeon E5-2680 v3 @ 2.50GHz，SSD 读写约 888MB/s，全国三网 Ping 平均 58ms 左右（联通约 61ms、移动约 53ms）；100 并发、10,000 请求压测下平均响应 112ms、失败 0 次，CPU 占用 60%~75%。数据来源：猎者出海（https://www.liezhe.com/hostkvm/），采集于 2026-11-07。

VPS 小学生对香港 CTG 机房 2C2G 机型的测试：E5-2697A v4 双核 2.60GHz，40GB 硬盘平均读写 415MB/s，内地 Ping 58ms；300Mbps 端口下三网下载多数超过 200Mbps，上传也在 200Mbps 左右；该机为香港原生 IP，可解锁港区 Netflix、美区 TikTok、Disney+，YouTube 峰值 14 万+ kbps。数据来源：VPS小学生（http://mp.weixin.qq.com/s?__biz=MzA5NTEzOTkyMg==&mid=2247509211&idx=1&sn=27479c534d2b57042692f0a6756a8cd7），采集于 2026-11-07。

能得出的：延迟确实低，58ms 对港机是合理值，两组独立测试落在同一数值；硬盘不是瓶颈，415MB/s 与 888MB/s 的差异来自机型与批次，但都远高于机械盘；线路不对称，去程直连、回程绕路是「CTG 优化」的典型特征——它适合「用户来访问你」，不适合「你主动去拉大文件」。

不能得出的：原生 IP 不是保证，那是批次运气，官方从未写进产品承诺；35Mbps 不是永远够用，一个 3MB 首屏在百人并发时会瞬间打满；99% 在线率不等于稳定，换算下来每月约 7 小时不可用，属行业中位。

第三方对官方规则的整理还指出：流量双向计费、带宽共享（承诺 20%~80%）、无管理且不支持 ISO/dd。数据来源：VPS乐园（https://vpscn2gia.com/hostkvm-review-2026），采集于 2026-11-07。

以上第三方实测受时间、机房、运营商与库存影响，本站未复现；以商家实际业务为准。

💡 港机的「58ms」是去程的功劳，「下东西慢」是回程的锅。用 mtr 把两个方向都看一遍，比看任何评测表格都准。

优点。 线路分工诚实：三条线接驳哪几家运营商、端口多少、适合谁，官方写得具体。CN2 GIA 的稀缺性真实存在——三网各走独立通道，晚高峰不与国际出口抢带宽，这是 35Mbps 敢卖 $8 的底气。硬件不虚标，两组实测 SSD 读写 415MB/s 与 888MB/s，RAID-10 对建站友好。门槛也低：支付宝国际与 PayPal 在官方清单内，六个机房各给独立 LG，退款四种情形都写了处理方式。

缺点。 第一，「线路越好、带宽越细」是结构性约束，加钱也解决不了：$60 的旗舰只有 35Mbps，$28 的给 100Mbps 却降一档线路，没有「又稳又快」的档位。第二，回程不对称，电信与联通绕日美，只有移动直连，「ping 58ms」与「下载速度」是两套体验。第三，价格信息混乱，库内互相比价就倒挂，第三方按官网整理的价格又显示 2026-04-11 已调价，库内 $6.4 起很可能已是历史价。第四，退款窗口窄且叠加审核延迟。第五，风控会直接拒单，评级异常不做人工放行。第六，无管理且锁死镜像，不支持 ISO 与 dd；支付方式还有一半未核实。

这些人群不适合：大带宽分发、视频、图床用户；电信或联通为主、在意下载速度的人；把「原生 IP 解锁流媒体」当刚需的人；必须用微信或银联付款的人；需要有人帮着配环境、排障的人。

决策清单，下单前逐条打勾：

  • 访客主要用哪家运营商？ 电信/联通为主且在意吞吐，先做回程 mtr，别只看 ping。
  • 要带宽还是要线路？ 分发类选 100Mbps 档，建站类选 35Mbps 的 CN2 GIA，别指望兼得。
  • 算过每 GB 单价吗？ 6G 档 $1.33/GB 优于 4G 档 $2.4/GB，别按型号数字排序。
  • 确认年付没有折扣吗？ $96/年 约等于 $8/月，与月付同价，首单没理由年付。
  • 在官方 LG 上测过了吗？ 六个入口见第四节，晚高峰必须复测。
  • 支付方式核对了吗？ 支付宝、PayPal、信用卡 supported；微信、银联、Apple Pay、Google Pay、加密货币、电汇全部未核实。
  • 退款边界清楚吗？ 3 天内、收 $1、违规不退；开错区域 24 小时内重下单、48 小时内全额退。
