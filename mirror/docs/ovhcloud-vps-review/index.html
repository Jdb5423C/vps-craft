# 1. 它卖的其实不是便宜

OVHcloud 的起步价确实低，但护城河不在 VPS 上。第三方总结其优势时反复提到的关键词是三个：自有网络、自研服务器与液冷、抗 DDoS 默认包含（数据来源：1VPS，https://1vps.com/review-ovh ，采集于 2026-11-07）。垂直整合的直接结果是同规格独服报价往往比云厂商低一截，而 VPS 更像引流产品。对普通用户意味着两件事：

  • VPS 是「够用级」而非「极致级」：同价位在低价年付商那里能买到更大内存和更多流量，但拿不到欧洲本土机房、自带抗 D 与正规发票。
  • 独服才是主战场：Rise-1（6C / 32GB / 1TB NVMe，$56.99）就是代表，同配置在云厂商那里月账单通常是三到五倍。

# 三、低价档的真实边界

# 1. 20GB 是第一道墙

算一笔账：Debian 12 minimal 约 1.2~1.8GB，Docker 与工具链 2~3GB，一个运行时 0.8~1.5GB，两个镜像 2~4GB，日志与缓存 1GB 起。留给业务的余量通常在 8~11GB，只要开始留一周日志、本地备份一次数据库，数字就会迅速见底。而且 VPS 扩容通常不是加钱加盘，多数情况要换套餐、重装系统。

2GB 内存跑 Debian + Nginx + 一个应用够用，真正的瓶颈是磁盘：没有空间承受一次意外的日志暴涨。真要用这档，建议 journald 只存内存、容器日志限制 10MB×3。

# 2. 「1000TB 流量」该怎么读

四档 VPS 的流量都标 1000TB/月，端口速率未标注。这个数字的实际含义是「不按流量计费」，正常业务几乎跑不满；真正限制你的是端口带宽。流量额度与端口速率是两个独立参数，Rise-1 标注了 1Gbps，四档 VPS 没有，下单前需去官方页面确认。

# 3. 什么时候该直接上独服

判断很简单：当瓶颈是「邻居」而不是「配置」时。VPS 的 4 核共享物理核心，独服的 6 核独占。游戏服、实时转码、CI 编译农场，或任何对延迟抖动敏感的场景，Comfort 档再贵也解决不了，$56.99 的 Rise-1 反而更省钱——它省掉的是排查「为什么晚高峰卡」的时间。

💡 选档口诀：静态站/探针选 $3.5；博客/小 API 选 $6；WordPress/中型应用选 $11.5；多容器/CI 选 $23；一旦开始怀疑「是不是邻居在抢资源」，直接跳独服，别在 VPS 线上继续加钱。

# 2. 退款：14 天撤回权，但不是无条件全额退

三个概念必须分开：

  • 法定撤回权：只适用于个人（Private）客户的新订单，窗口 14 天，无需说明理由、无需罚金。
  • 退款金额：撤回申请后 30 天内处理，按已用天数比例扣减，尽量原路退回。用了 10 天再撤回，拿回的不是全款。
  • 不适用对象：企业账户、续费订单、域名、Sectigo SSL 证书。

合起来的意思是：它给了你反悔窗口，没给你免费试用。

💡 下单前自检：先确认账户是个人还是企业（这决定有没有 14 天窗口），再用最小配置验证机房，不要一上来买年付。退款是「按天折算」而非「全额退还」，这和很多国内用户的直觉相反。
