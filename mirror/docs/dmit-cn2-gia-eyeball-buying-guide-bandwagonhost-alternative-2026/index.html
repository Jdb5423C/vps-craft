# 2. 三大硬件平台代际（AS3 vs AN4 vs AN5）

  • AS3（AMD EPYC 7003 / Zen3）：2026 年 DMIT 货源最稳、价格最便宜的性价比主力平台。日常建站、跑代理或拼车，选 AS3 性价比最高！
  • AN4（AMD EPYC 9004 / Zen4）：实测搭载 EPYC 9654，同档位比 AS3 贵 $10~$15/月，多核性能显著提升，是 2026 年 10 月补货的过渡主力。
  • AN5（AMD EPYC 9005 / Zen5）：性能怪兽！同核数下多核跑分约为 AN4 的 2.6 倍，适合重度编译与高并发数据库，但 2026 年库存偏紧、价格最高。

# 📚 本文知识溯源、维基百科词条与权威技术文献引用

为保障本文所涉骨干网自治系统编号（ASN）、硬件微架构代际及跨洋路由协议的科学性与准确性，文中技术论述均考证自以下官方技术标准与权威词条：

  1. 中国电信下一代承载网（CN2 GIA / AS4809 & AS23764）
    • 维基百科官方词条：中国电信下一代承载网络 (ChinaNet Next Carrying Network)
    • 考证要点：DMIT 旗下 Pro (Premium) 系列三网回程均强制路由至电信 AS4809（59.43 高优节点）及亚太方向 AS23764 国际精品专线，具备最高等级的跨洋拥塞控制优先级。
  2. 中国联通工业互联网（CUII / AS9929）与中国移动国际精品网（CMIN2 / AS58807）
    • 维基百科官方词条：中国互联网骨干网 与 中国移动国际 (CMI)
    • 考证要点：DMIT 洛杉矶 EB (Eyeball) 系列回程采用分网直连架构，联通方向直连 AS9929 政企专网，移动方向直连 AS58807（CMIN2），规避跨网结算瓶颈。
  3. AMD EPYC 服务器处理器微架构演进（Zen 3 / Zen 4 / Zen 5）
    • 维基百科官方词条：AMD EPYC 处理器架构列表 (Milan / Genoa / Turin)
    • 考证要点：DMIT 硬件命名中，AS3 对应 EPYC 7003 系列（代号 Milan，Zen 3 架构），AN4 对应 EPYC 9004 系列（代号 Genoa，Zen 4 架构），AN5 对应最新 EPYC 9005 系列（代号 Turin，Zen 5 架构）。
  4. 自治系统边界网关协议与国际 Tier 1 互联标准（BGP-4）
    • IETF RFC 核心标准：RFC 4271 - A Border Gateway Protocol 4 (BGP-4) 与维基百科 Tier 1 network (一级运营商网络) 词条（涵盖 Telia/Arelion、Cogent、Zayo、NTT 等国际骨干网对等互联机制）。
