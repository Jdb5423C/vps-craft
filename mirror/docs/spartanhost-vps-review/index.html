# 一、先把三个数字校准：$4、20G、CMIN2

官网首页写 Cloud VPS From $3.50/mo，数据库最低价 $4/月，而西雅图 CMIN2 起步 $24。三个数字对应三档东西，先分清再谈值不值。

第一个校准：$4 是达拉斯，不是西雅图。 数据库 32 条里美西 22 条、美东 10 条，价格 $4 ~ $115.2。$4 的 spartan-dal-1g 给 2 核 1GB / 15GB NVMe / 2TB @ 10Gbps；西雅图只有 CMIN2 一条线，4 核 4GB 起，$24。这不是同一台机器的两个配置，是两种用途。

第二个校准：20G 是西雅图的上限起点，达拉斯是另一个体系。 官网原文分得很清楚：Seattle - attacks up to 200Gb/s，机房页写 20 Gb/s DDoS Protection against TCP attacks (upgradable to 200Gb/s)；达拉斯是 CosmicGuard, attacks 1Tb/s+。也就是说，西雅图默认 20G、可付费升到 200G，达拉斯/阿什本默认就是 T 级。「全系高防」是真的，但等级与类型在不同机房并不一样。

第三个校准：CMIN2 只有一条线，CN2 GIA 与 9929 是另一回事。 数据库 32 条全部标 BGP，只有 spartan-sea-cmin2-4g 的名字里带 CMIN2。官方页面列出的上游包含 China Unicom (AS4837)、China Mobile (CMIN2/AS58807)、China Telecom (AS4809)、Arelion、GTT——AS4809 是电信 CN2 的 AS 号，但「上游里有 CN2」不等于「每条路由都走 CN2 GIA」；9929（联通精品网）在官方页面与本地数据里都没有出现过。中文测评里常见的「斯巴达全线 CN2 GIA」「支持 9929」，多数是把上游 AS 号当成了产品承诺。

💡 一句话预期管理：$4 买的是「美国本土 + 基础防护」，$24 买的才是「回国优化 + 高防 + 新硬件」。别拿 $4 的预期去验收 $24 的东西，也别拿 $24 的价格去要求全线。

# 二、高防的边界：防什么、什么时候触发、被打之后

「自带高防」四个字被引用得太多，具体条款被引用得太少，这一节补齐后者。

# 防护是默认开启的，不需要额外下单

西雅图的 20Gb/s 防护、达拉斯的 CosmicGuard 都写在套餐里，属于机房/上游层面的清洗，不需要装软件，也不需要单独购买防护包。唯一可能付费的动作，是西雅图结账时把防护升到 200Gb/s。第三方称西雅图标配为 CNServers 的 20Gb/s（20Mpps），升级档 200Gb/s（200Mpps）。

数据来源：bwgcn2gia（https://bwgcn2gia.com/?p=395），采集于 2026-11-07。第三方实测受时间、机房、运营商与库存影响，本站未复现。

# 「防什么」要看官方措辞，不要看宣传图

官网首页的总体表述是 protection against all kinds of known attacks, this includes layer 3 and 4, and 7 protection，但落到具体机房，西雅图写的却是 20 Gb/s DDoS Protection against TCP attacks。这个差别很重要：

攻击类型西雅图（20G 档）达拉斯 / 阿什本（CosmicGuard）
SYN Flood / ACK Flood 等 TCP 洪水官方明确覆盖官方明确覆盖
UDP Flood、DNS/NTP 反射放大官方未明确承诺官方称 L3/L4 覆盖
HTTP Flood、慢速 CC 等 L7 攻击官方未明确承诺官方称含 L7 识别
超大流量（>200Gb/s）需升级或由上游处置官方标称 1Tb/s+

结论：业务以 UDP 为主（游戏服、语音、部分代理协议）的话，西雅图这条线的防护承诺并没有覆盖到你头上。 要稳就选达拉斯/阿什本，或提前问清防护类型——这是官方自己划的边界。

# 被打之后会发生什么

清洗是策略驱动的自动动作：没有「一键开启」的开关，也不需要提前报备，机房侧检测到攻击特征即牵引。除此之外官方只写了 Automatic DDoS Mitigation（自动清洗）、24/7 Attack Monitoring（监控）与防护容量，未公开触发阈值、判定窗口、是否邮件通知、是否自动 null-route（黑洞）与解封流程。

能确定的是行为模式：流量被牵引到清洗设备后路径变长，表现为延迟抬升与轻微丢包，攻击结束自动回切。超过套餐防护上限时，通常由上游黑洞处置，表现是全端口不可达——这是行业通例，不是官方承诺。阈值不公开还带来一个后果：小额攻击是否触发清洗、触发后正常流量会不会被一起牵引，只能实测。第三方称常见 TCP 洪水「能在数秒内完成清洗」，属实测口径，本站未复现。

真正要开工单确认的只有一句：被攻击期间产生的流量，算不算月额度？ 官方页面没写，而一次持续几小时的 10Gbps 攻击，理论上就是几十 TB。

# 流量与端口：10Gbps 是突发能力，不是月均承诺

数据库里 BGP 系列端口统一标 10Gbps，流量 2TB~9TB；CMIN2 是 200Mbps 上行 / 10Gbps 下行、2TB。算一下就知道落差：

  • 10Gbps 跑满，2TB 只要约 27 分钟（2048GB ÷ 1.25GB/s ≈ 1638 秒）；
  • 200Mbps 跑满，2TB 约 22.8 小时；
  • 2TB 摊到一个月，平均只有约 6.2Mbps。

10Gbps 是给你「短时间冲一下」的，不是「持续跑满」，真正决定体验的是月流量额度。CMIN2 的 2TB 在优化机型里偏紧，第三方的吐槽也直接：这个配置下 2TB 对跑流量、做中转的用户「很容易就爆掉」。

超量之后怎么处理，官方页面没有统一写明。第三方称 CMIN2 系列超量后「通常限速到 5Mbps 左右」；BGP 系列是否同样限速、还是按 $/TB 计费，本文未能核实。不要假设「不限量」——每档套餐都写了具体 TB 数。

数据来源：vpsquery（https://www.vpsquery.com/archives/7414），采集于 2026-11-07。第三方实测受时间、机房、运营商与库存影响，本站未复现。

# 三、线路辨析：BGP、CMIN2、CN2 GIA 与「9929」

BGP 是基本盘。达拉斯、阿什本与西雅图大部分套餐都走普通 BGP，回国走 163/4837/CMI 这类常规出口，晚高峰会抖。第三方观察西雅图三网 160~190ms、晚高峰可能上 200ms 以上；达拉斯与阿什本 200~250ms。面向海外用户够用，面向国内只能算「能连」。

CMIN2 是唯一做了回国优化的产品线。它是中国移动的精品线路（AS58807），对标 CN2 GIA，三网直连、晚高峰相对稳。第三方给出的入门配置是 4 核 4GB / 100GB NVMe / 200Mbps / 2TB / $24。它优化的是回程质量，不是延迟量级——到国内仍是 150ms 起步，只是丢包与抖动更可控。

CN2 GIA 与 9929 需要澄清。AS4809 确实出现在官方上游列表里，但那是供应商清单，不代表任何一条套餐承诺全程 CN2 GIA；9929 从未出现在官方页面与本地数据中。中文测评那句「斯巴达支持 CN2 GIA/9929」，多是把上游 AS 号当成了产品承诺。真要 GIA 级的确定性，站内对 搬瓦工全产品线 与 DMIT Pro Eyeball Tier1 的拆解更值得参考。

# 「高防 + CMIN2」这个组合到底值多少

拆成三份：CMIN2 解决「晚高峰不绕」，20G 起步的防护解决「被打不立刻挂」，7950X + NVMe 解决单核性能。单看任何一项都有更便宜的替代品；三项同时具备且月付 $24 的，选择确实不多。它的价值不是「便宜」，是省掉了「拼中转 + 买高防 + 换硬件」三次决策。

代价同样清楚：2TB 流量、200Mbps 上行、产品线也不算成熟。做「国内访问的中型站点 + 怕被打」，它合理；做「跑流量、做分发」，2TB 第一周就撞墙。

# 退款：48 小时，且只给新用户

官方 TOS（Last Updated 9th September 2026）的规则可以压缩成五条：

  1. 窗口 48 小时，自发票付款时刻起算，不是「收到机器后 48 小时」；
  2. 仅限新用户的首个服务、首个计费周期——月付即 1 个月，季付即 3 个月；
  3. 适用于 VPS、Minecraft、Web Hosting 与防护，独立服务器不参与；
  4. 老用户彻底失去资格：账户有过任一历史订阅就不再享受；
  5. 扣网关手续费，通常 $0.30 + 最高 5%，且必须通过账单工单申请；拒付视为欺诈。

第 4 条最易被忽略：很多人以为「先买月付试水」，但账号只要有过一台机器，策略就失效。想保留退款权，必须用全新账号。

第 1 条决定节奏：48 小时不是「慢慢用两天」，而是「24 小时跑完测试、留 24 小时沟通」——先 ping + mtr 看回程，再 curl 拉测速文件，最后跑磁盘与 CPU 基准。

# 优点

  1. 防护是标配不是加购：$4 的达拉斯入门机也有机房级清洗，同价位少见。
  2. 达拉斯/阿什本规格高：CosmicGuard 标称 1Tb/s+ 且含 L7，适合公开站点。
  3. CMIN2 补上「优化 + 防护」的交集：二者兼有的选择不多，$24 算克制。
  4. 硬件不糊弄：7950X + NVMe，同价位普遍还是 E5 老平台。
  5. 对中文用户友好：官方 FAQ 明确列支付宝，LG 与测试文件齐全。

# 缺点与不适合人群

  1. 「高防」被过度简化：西雅图页面只写 TCP，UDP 与 L7 没承诺，拿去防游戏服攻击可能落空。
  2. 线路宣传与产品不符：全线 BGP，只有一条 CMIN2，CN2 GIA/9929 缺依据。
  3. 流量给得紧：CMIN2 2TB、BGP 系列 2~9TB，10Gbps 端口容易让人误判余量。
  4. 关键规则不透明：清洗阈值、是否通知、攻击流量是否计费，官方均未公开。
  5. 退款窗口短：48 小时、仅新用户首单、独服不退、还扣手续费。
  6. 库存标注混乱：32 条里 24 条为 unknown。
  7. 不适合：把高防当「免疫一切」的人、要 9929/GIA 确定性路由的人、月流量超 5TB 的人、想拿退款当试用期的人、需要中文客服的新手。
