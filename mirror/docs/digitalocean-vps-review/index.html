# 一、计费模型：按秒结算、月付封顶，关机照样扣钱

按秒计费。 官方定价页写明：自 2026 年 1 月 1 日起，Droplet 改为按秒计费，最低收费为 60 秒或 $0.01，两者取高。页面标注 $4 档时价为 $0.00595/小时，开三小时做压测，账单不到 2 美分（数据来源：DigitalOcean 官方定价页（https://www.digitalocean.com/pricing/droplets），采集于 2026-11-07）。

但有两个边界：最低按 60 秒计，开了立刻删不会变成 $0；按秒只影响计算资源，块存储、快照、保留 IP 仍按各自周期计费。

月付封顶。 官方页写的是「monthly caps or usage-based pricing」，套餐型 Droplet 无论当月多少天、开多少小时，账单都不超过月价，7×24 常开不必担心 31 天的月份多付一天。会让账单超支的是不封顶的附加项：超额出站流量、快照与块存储。

关机仍计费。 实例存在即占用资源，占用即计费。点 Power Off 之后，vCPU、内存、系统盘和公网 IP 仍挂在账户下。第三方中文评测也记录了这一点：DigitalOcean「关机照样收费，要销毁才停」（数据来源：猎者出海（https://www.liezhe.com/zhifubao-vps/），采集于 2026-11-07）。

最常见的翻车是：开一台 $24 机器试用，觉得不合适就关机，然后忘了，几个月后账户已累积欠款。避免方法只有一个——不用了就 Destroy；要保留环境就先做快照再销毁。

💡 把 Droplet 当「一次性用品」：测试机创建时就设删机提醒；需要保留系统状态就做 Snapshot（$0.06/GB/月），再从快照重建。养成这个习惯，账单会非常可预测。

三条实用结论：

# 2. 退款：官方原文只有一句话

官方退款专页（last_updated 2024-03-12）正文极短：

We do not offer refunds.

If there are extenuating circumstances, contact support.

即：不退款；特殊情况联系客服。没有 7 天，没有 30 天，没有「未使用余额可退」。本站数据库的退款字段同样是 supported=false、windowDays=null。

因为先用后付，正常情况账户里没有「预付余额」可退；但已产生的账期费用、年付或预留实例的钱，按条款拿不回来，客服酌情处理是人情，不是权利。

因此有一条铁律：不要一次性预付长期费用，也不要为「锁定优惠」提前充值。按月跑、按需销毁，是这套模型下最安全的姿势。

# 五、测速 IP 与下载文件：官方没有公开入口，只能自测

必须如实说明：DigitalOcean 没有提供公开的测速 IP 列表与固定下载文件，核查范围内未找到可引用的官方入口。因此不提供任何测速 IP——编一个既无用也误导。

替代方案是「开一台按秒计费实例自测」，成本极低，测的还是你真正会买到的那条链路：

  1. 创建实例：选目标机房，$4 档即可，测完立即 Destroy；
  2. 测延迟与路由：本地执行 ping -c 30 <实例IP>，再用 mtr -rwzbc 100 <实例IP> 看是否绕路、跳数是否异常；
  3. 测下载：实例上用 dd 生成 100MB 文件，本地用 curl -o /dev/null -w "%{speed_download}\n" 拉取，重点看 20:00–23:00 的表现；
  4. 测上传与回程：实例装 iperf3 -s，本地用 iperf3 -c 反向上传，观察你这条宽带到该机房的上行能力。

按官方标价，跑三小时成本约 1.8 美分，比任何第三方报告都更贴近真实体验。

容易忽略的三点：出站流量计入额度，$4 档只有 500GB，反复拉文件会消耗；同机房不同母机表现可能不同，重要业务建议开两台交叉验证；IP 段会影响回程路由，第三方报告的 IP 与你分到的未必同段。

💡 最省钱的自测流程：$4 档开一台，跑完 ping / mtr / 下载 / iperf3 四步，截图存证后 Destroy。全程不到一小时，成本不到 1 美分，却能把「买完才发现线路不行」的风险降到最低。

# 2. 优点

计费粒度细。 按秒、60 秒起算、月付封顶，让「临时用一下」的成本几乎可忽略，试错边际成本接近于零。

控制台、API 与文档是核心竞争力。 创建实例、挂快照、调防火墙、绑浮动 IP 全流程可 API 完成，文档质量属第一梯队；对把基础设施写进代码的团队，这比便宜 5 美元重要。

生态完整。 快照 $0.06/GB/月，备份按 Droplet 价格 20%（周）或 30%（日）计费，另有块存储、对象存储、托管数据库与 Kubernetes。

支付宝 $0 预授权降低上手门槛。 不用先充钱，月末按用量扣美元，比「先充值、余额不退」对试用更友好。

# 3. 缺点与不适合人群

关机仍计费且不退款。 「忘了删机器」会持续产生费用，一旦扣款又拿不回来。

没有回国优化。 核心诉求是「国内访问快」的话，它连承诺都没有。站内 搬瓦工全产品线评测、DMIT Pro Eyeball Tier1 评测、HostDare CN2 GIA 评测 才是为这件事准备的。

亚太覆盖薄。 没有日韩港节点，做东亚业务只能从新加坡或班加罗尔绕。

单价高于年付商。 1C1G 年化约 $48~$84，RackNerd 全价位评测 的年付特价机常在 $20 上下，价差买的是弹性与生态。

低价档配置口径漂移。 $4 档数据库记 1GB、官网记 512MiB；$12 档 vCPU 数两处也不一致，下单前逐项核对。

不适合：预算优先、只要一台长期在线便宜机器；需要国内直连；需要日韩港节点；会忘记删机器的人。

# 5. 决策清单

  • 我会记得销毁机器吗？ 答案是「可能会忘」，就先设日历提醒，或者别用按量计费平台。
  • 机房离我的用户近吗？ 欧美选欧美，东南亚选新加坡；面向日韩请换一家有当地节点的商家。
  • 我要单核性能还是并行度？ 单线程应用优先 Premium 高频档，并发应用优先双核档。
  • 核对过结算页配置吗？ $4 档的 512MB/1GB、$12 档的 vCPU 数都有口径差异，以结算页为准。
  • 接受「不退款」吗？ 接受再下单，不要预付长期费用。
  • 支付方式准备好了吗？ 支付宝可用（$0 预授权），微信不支持，银联按卡组织受理，Apple/Google Pay 有浏览器限制。
  • 测过线路吗？ 官方没有公开测速 IP，按第五节开一台 $4 实例自测三小时，成本约 2 美分。
  • 把优惠码当长期折扣了吗？ 唯一登记的 LOWENDBOX 已于 2021-06-30 到期，未实测、不建议使用。
  • 有异地备份吗？ 销毁即清空系统盘，快照仍在本账号内，重要数据必须另存一份。

一句话总结：DigitalOcean 不是「便宜的 VPS」，而是「规则清晰、计费精细、生态完整、容错率低」的开发者云。它奖励有计划的人，惩罚健忘的人。
