# 一、 云悠全系产品架构与计费形态深度拆解

在云悠目前的后台商品库中，主要将机器划分为两大体系：经典云服务器（CVM） 与 流量型云服务器（TCVM）。理解这两者的差异是避坑和理性选购的第一步：

# 1. 经典云服务器（Classic Cloud Server - CVM）

  • 定位：面向严肃建站、高稳定代理与生产力场景。
  • 网络特点：全线标配针对中国大陆的顶级优质回国优化网络（如移动 CMIN2、联通 AS9929、电信 CN2 GIA/VIP、香港荃湾直连等）。
  • 硬件规格：标配独立 IPv4，配备 30GB 纯 SSD 存储，CPU 广泛采用高性能 AMD EPYC 7K62 霄龙处理器或 Intel Xeon 高频系列，Sysbench 单核性能可达 1400+ 分，远远抛离老一代 E5 机器。
  • 计费细分：
    • 流量型（Traffic）：给到 100M~150 Mbps 弹性突发大带宽，每月赠送 400G~1000GB 双向流量。用完后支持以 ¥10 / 400GB 极低成本弹性加购，适合带宽需求大但月总流量可控的用户。
    • 独享带宽型（Bandwidth）：给到 10M~30 Mbps 独享物理带宽，月流量完全不限（0 限制），绝不产生超额流量账单，适合挂机、自建网盘及免流场景。

# 2. 流量型云服务器（Traffic Cloud Server - TCVM）

  • 定位：面向大带宽突发、超大规模数据吞吐、海外业务运营与特殊网络属性（双 ISP 家宽/动态 NAT）。
  • 网络特点：既有主打美国原生双 ISP 住宅属性的商用出海系列（US4），也有直连日本骨干的 3G~5Gbps 极致大管子（JP1），更有针对海外大文件备份分发的 1Gbps 国际大带宽系列（US6 / US7 / GB1 / HK6），每月流量直接飙升至 4TB ~ 16TB。
  • 价格优势：大带宽流量型机器月付大多仅需 ¥15.99 ~ ¥37.99，在单位流量成本上具备极高优势。

# 二、 南北地域网络选型深度分析（以秦岭-淮河为界）

中国互联网的国际出口带宽主要收敛于三大国际出口局：广州出口局、上海出口局与北京出口局。由于地理物理距离海缆陆缆走向的物理限制，南方和北方用户在选择 VPS 节点时存在着根本性的网络逻辑差异：

# 1. 中国南部地区（华南、华东沿海、西南等）

地理覆盖：广东、广西、福建、海南、浙江、上海、江苏南部、江西、湖南、湖北、四川、重庆、贵州、云南等。

  • 出口机理：南方省份的国际流量绝大多数经由 广州出口局（经由汕头、香港登陆海缆）或 上海出口局（经由崇明岛海缆）直接跨洋出境。
  • 最优机房剖析：
    1. 香港荃湾 HK5 / 九龙 HK4：
      • 这是南方沿海用户的天然地理优势节点。按物理距离估算，广东本地直达香港荃湾 HK5 理论延迟约 15ms ~ 25ms，华东地区（上海、浙江、江苏）约在 30ms ~ 45ms 之间。适合用于免备案建站或 API 中转。(注：本站未实际上机测试香港机型，基于地理与线路属性理论分析)
    2. 洛杉矶 C.Std.T 系列（CMIN2 + 9929）：
      • 这是南方用户连接美西的“物理极限之选”。根据我们对该系列 Pro 机器的上机融合怪脚本与 NextTrace 抓包实测，该系列的移动 CMIN2 回程链路直接从洛杉矶跨越太平洋砸入上海移动节点（AS58807 洛杉矶-上海海缆），单向跨洋耗时仅 126ms！联通走 AS10099 出海接 AS9929 到上海，实测延迟也在 135ms 左右。对于南方的移动和联通宽带用户而言，跨洋体验丝滑至极。
