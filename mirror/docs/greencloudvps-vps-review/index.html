# 一、价格体系：$6/月 与 $15/年 为什么能同时存在

产品线典型价格交易条件适合谁
常规 KVM / Ryzen$6–$80/月月付、新客户首台 7 天内可退、可加配要灵活、要试错、跑正式业务
10G KVM（美欧）$12/月起月付、10Gbps 共享端口大流量但不在乎回国延迟
年付促销 / 黑五 / 闪购$15–$84/年仅年付、页面标注不退款预算极低、能接受一次性投入

$15/年 折合 $1.25/月，不到 $6/月 的两折。价差只能来自四处：共享 CPU、共享端口、较老的硬件、不退款的条款。

# 二、亚太线路：香港 10Mbps、东京抽签、新加坡分两档

# 1. 香港：10Gbps 端口，10Mbps 回国

官方 Ryzen 产品页有一句原话：we only offer 10mbps Direct bandwidth to China on our Hong Kong VPS——香港 VPS 直连中国大陆只有 10Mbps。10Mbps 满速约 1.25MB/s，十几个人同时打开页面就会排队。香港机房的价值是"距离近、延迟低"，但低延迟换不来吞吐。

所以"香港 10Gbps 闪购"的正确读法是：10Gbps 是本地端口，回程只有 10Mbps，适合面向香港或海外的服务、跳板、轻量 API，不适合大陆访客建站。

# 2. 东京：IIJ 为主，软银看运气

东京机房托管在 xTom，线路非自营，分配带有随机性。第三方实测记录显示：多数 IP 走 IIJ（电信双程 IIJ、联通去程 IIJ 回程 Level3、移动直连），白天延迟低、晚高峰丢包偏高；少数 IP 能分到软银 BBTEC，三网软银直连回国，实测电信约 75ms，集中在 43.x 与 85.x 段。

同一款东京 VPS，两人买到的体验可能完全不同。线路不可指定，开机后只能查路由再决定是否换 IP；换 IP 费用有 $2/次 与 $3/次 两种记录，本文不采信，以工单为准。

数据来源：索拉缤（https://sorabin.com/greencloudvps-luyun-pingjia-dongjing-ruanyin/），采集于 2026-11-07。第三方实测受时间、机房、运营商与库存影响，本站未复现；以商家实际业务为准。

# 3. 新加坡：普通线与 Premium 是两种商品

新加坡有 DC1、DC2 两个普通机房，以及一条 Premium 优化线：官方标注 CN2GIA / CU PREMIUM / CMI（东京为 CMIN2），配 EPYC Milan、NVMe RAID-10、每日备份，起价 $25/月（1 核 / 2GB / 20GB / 500GB @ 500Mbps），且分类页写明不退款。

与 $15/年 的 2GB 年付机价差 20 倍，买的不是 CPU 和内存，而是晚高峰回国的确定性。

💡 选线口诀：预算 $2/月 以内，就当"海外机"用；$25/月 且访客主要在大陆，再考虑 CN Premium；介于两者之间又非要中国优化，建议看专做 CN2 GIA 的商家，例如 DMIT Pro 系列评测 与 搬瓦工全产品线评测。
