# 一、先把三条线分清：Pro、Eyeball、Tier 1 不是「高配 / 中配 / 低配」

这是全文最核心的一节。DMIT 的产品线命名里，Pro、EB、T1 代表三套完全不同的网络产品，它们共用相似的硬件母机与控制面板，却在「流量从机房出来以后走哪条路回中国」这件事上做了完全不同的取舍。

# 1. Pro / Premium：以中国电信 CN2 GIA 为底座的顶级回国优化

Pro 是 DMIT 的旗舰系列。很多新手误以为 Pro 是三家运营商各走各的，这是最大的误区。落到洛杉矶（LAX）Pro 产品上，其核心路由策略是：

  • 三网回程统一强制走中国电信 CN2 GIA（AS4809）：无论访客是电信、联通还是移动，服务器往中国大陆发送数据时，回程全部切入中国电信顶级 59.43（CN2 GIA）骨干网回国；
  • 去程方向各自直连：电信走电信 CN2 GIA 直连，联通走联通骨干（4837/优化），移动走 CMI/CMIN2 直连；
  • 极佳的抗晚高峰拥塞能力：CN2 GIA 的价值不在于白天能跑多快，而在于北京时间每晚 20:30–23:00 全国国际骨干网严重拥塞时，它依然能维持低丢包和低抖动。

此外，DMIT 对 Pro 系列默认支持「超量降速不断网」（Traffic Limit Policy）：在控制面板可设置当月高速配额用完后，自动限速为 2Mbps ~ 10Mbps 无限量继续运行，次月自动重置。这彻底解决了建站用户担心「流量用超被停机或产生天价账单」的顾虑。

Pro 适合「业务不能卡」的场景：面向国内全网用户的企业站、核心 API 后端、远程办公跳板、对丢包零容忍的实时生产业务。

# 2. Eyeball / EB：针对不同机房的「平价替代」优化

Eyeball 是 DMIT 用来承接「想要优化回国、但不想付 CN2 GIA 昂贵溢价」的产品线。特别需要注意：不同机房的 EB 线路完全不同，切忌混为一谈：

  • 洛杉矶 EB（LAX.EB）：采用联通 AS9929 + 移动 CMIN2。移动回程走 CMIN2（AS58807 精品网），联通回程走 AS9929（联通精品网）。
    • 对联通与移动极度友好：走各自的二代精品网通道，晚高峰速度与稳定性逼近甚至在部分地区反超 CN2 GIA；
    • 电信用户的潜在风险（跨网 QoS）：电信用户访问洛杉矶 EB 时，回程通常借道 AS9929 或 CMIN2 回国，这属于跨运营商通信。晚高峰期间，电信骨干网与联通/移动骨干网的网间结算互联点极易发生拥塞（QoS），电信宽带用户可能会遇到显著的丢包与抖动。电信用户切勿盲目将 EB 当作无损平替。
  • 中国香港 EB（HKG.EB）：回程主打中国移动 CMI（AS58453）直连优化，而非 9929/CMIN2。对移动网络而言是顶级低延迟直连，对电信和联通则是普通直连。
  • 同价位资源更丰厚：$10.9 的 EB.TINY 给到 1.5TB / 2Gbps，而同价位的 Pro.TINY 只有 1TB / 1Gbps。DMIT 是在用更大的流量与带宽补贴 EB 在电信路由上的不足。

💡 一句话判断：如果你的主力访客是联通或移动，洛杉矶 EB 是「用更低成本换取上限体验」的极佳选择；如果你的业务核心面向电信用户，或者需要兼顾三网访客的无差别稳定，请加钱上 Pro。

# 3. Tier 1 / T1：国际大带宽，明确「不为中国大陆优化」

Tier 1 是最容易被贪便宜买错的一条线。它单价低、端口大、流量足，$6.9/月就能拿到 2TB @ 4Gbps，但官方在控制台与说明里明确标注：国际 BGP 互联，无中国大陆优化。

这意味着：

  • 它的目标是全球与美洲、亚太各地区之间的公网转接，不是回国直连。中国大陆三网访客走 T1，去程和回程均走普通 163 或 4837，晚高峰丢包率可能超过 20%~30%，且可能绕道欧洲或其他地区；
  • 它的强项是单价低、端口大、抗突发，适合用来做海外数据备份、CI/CD 节点、Docker 镜像源、面向欧美非大陆本土访客的外贸站，或配合前置节点做纯海外中转；
  • 香港 T1 与东京 T1 上游主要为 HKIX、NTT、Telstra 等国际交换中心与 Tier 1 运营商，亚太近场互联快，但不等于回大陆快。

# 1. 退款政策核心细则

官方退款规则主要分为两个周期：

  1. 3 天内全额退款：
    • 仅限新购订单、购买不超过 72 小时；
    • 实例累计已用流量不得超过 30GB；
    • 扣除或免除网关费用后原路返回。
  2. 30 天内按比例退款：
    • 购买不超过 30 天；
    • 退款额按「已消耗流量比例」与「已使用服务时长比例」中扣除较多的一项计算剩余价值。
  3. 退款即销毁：申请确认后，实例立即终止且数据全毁，不可逆。

# 2. 必须警惕的 TOS 不退款「红线」

很多人以为「买了觉得卡就能退」，这是导致退款被拒的最大诱因。官方 TOS 第 19 条列有详细的不予退款条件，其中最关键的一条是：

严禁以「网络质量不符合主观预期 / 访问速度慢 / 延迟高 / 路由不理想」为理由申请退款！

如果用户在退款工单里写“我觉得晚高峰卡顿、要求退款”，客服会直接援引 TOS 19.3 条款判定不符合退款要求并拒绝退款。

无损试错技巧：

  • 想要验证网络，建议先开月付入门款；

# 六、为什么比同类贵？缺点与不适合人群

# 1. 昂贵的溢价究竟花在了哪里？

相比于年付 $20 的普通美西主机，DMIT 月均 $10 起步的定价明显偏高。其成本主要消耗在五个不易直观量化的环节：

  • 顶级上游带宽采购成本：中国电信 CN2 GIA（AS4809）与联通 AS9929 的每兆带宽采购单价，是普通 163（AS4134）和普通 4837 的数倍甚至十倍以上；
  • 控制面板自助免费换 IP（核心权益）：对于 Pro 和 EB 系列的特定周期订单（如季付及以上），DMIT 官方在后台提供每 15 天可免费自助更换一次被封锁 IPv4 的权益。而在普通低价 VPS 厂商处，单次更换被阻断 IP 需额外付费 $3 ~ $5。这项售后服务是支撑其高单价的关键护城河；

根据DMIT更新后的TOS及官方文档，免费更换IP需要同时满足：
实例已购买至少7天（从第8天起）；
距离上次更换IP（含付费）至少过去15天；
ICMP和所有TCP端口均已被屏蔽——这是最关键的一条。如果ICMP还能通（能ping通），即使TCP被封，也不符合免费更换条件，需要付费($5)更换；
服务剩余有效期不少于7天。

此外，“自助”的程度也因产品线和机房而异。LAX Pro & EB的免费更换需要人工审核，付费更换才免审核；HKG & TYO区域的Pro & EB免费和付费更换都需要审核。V2EX上有用户反馈，正是因为ICMP是通的，免费更换被拒绝，最终付费才得以解决

  • 超量降速保护保障：开通 Traffic Limit Policy 后，月度高速流量超标不会面临关机断网或高额账单，而是降速为 2Mbps ~ 10Mbps 不限量继续运转；
  • 硬件平台无超售冗余：母机广泛采用 AMD EPYC 7003 (AS3) 及 EPYC 9005 (AN5) 处理器，配备企业级 NVMe 固态硬盘，实测顺序读写在 800MB/s 以上，严格控制母机超售率；
  • 自建骨干网络与自持 ASN：持有美国 AS906 与亚太 AS32519 自主调度，具备跨区域私有骨干网互联能力。

# 3. 客观缺点与避坑指北

  1. 贵得只体现在线路上：如果你的业务是离线编译、跑自动化脚本、挂探针，DMIT 的 CPU 和内存性价比极低；

  3. T1 极易被新手误买：看到 $6.9/月 4Gbps 冲动下单，买来发现回国全走普通 163 甚至绕路，晚高峰看视频卡顿；

# 4. 明确不适合的人群

  • 单台预算在 $5/月以内的个人玩家：建议转向普通直连或普通 BGP 商家；
  • 主力访客为电信、但试图买 EB 省钱的站长：晚高峰网间结算抖动会破坏业务体验，建议一步到位选 Pro；
  • 以为「买了不爽就能全额退款」的新手：DMIT 的 TOS 极为严格，不支持无理由主观网络退款；
  • 大容量存储或 PT 下载需求：DMIT 存储空间单价高，不适合用作存储大盘鸡；
  • 需要企业级书面 SLA 赔付合同的核心政企业务：零售型 VPS 并不提供包含分钟级停机赔偿的商业 SLA 协议。
